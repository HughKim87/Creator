# 최종 영상 검수

이 스킬은 8단계 최종 검수를 담당한다.
AI는 문제와 위험을 찾고 정리한다. 최종 업로드 판단은 사용자가 한다.

## 입력

- 완성본 또는 러프컷 영상
- `outputs/07_edit_export/CURRENT.json`, 안정된 `source_id`, 기준 버전
- `outputs/06_analysis/source_asset_manifest.csv`와 7단계 `changed_ranges`
- 5단계 기획서
- 6단계 후보지도
- 7단계 컷리스트/XML/EDL/러프컷 산출물
- 자막 파일 또는 자막 반영본
- 사용자가 특히 확인하고 싶은 항목

## 증거 구분

- 원본 내용·사건·대사는 원본 시간 `asset_ids`와 자막·오디오로 확인한다.
- 자막 배치·효과·합성·색·렌더 오류는 현재 버전의 `render_evidence`로 확인한다.
- 편집본 캡처를 원본 내용 증거로 재분류하지 않는다.
- 컷 변경은 `changed_ranges`를 우선 검수한다. 전역 자막·효과·색·오디오 변경은
  초반·중간·후반 대표 표본이나 영향받은 전체 트랙을 추가 검수한다.

## 검수 축

1. 기획 의도
   - 완성본이 5단계 컨트롤링 아이디어를 담고 있는가
   - 대사 스파인의 시작, 변화, 결말이 남아 있는가
   - 중요한 반례나 약점이 무시되지 않았는가

2. 흐름
   - 도입이 약속한 내용을 본문이 실제로 다루는가
   - 사건, 결과, 반응이 끊기지 않는가
   - 반복 장면이 과하게 남지 않았는가

3. 원본 보호와 기술 상태
   - 원본 영상과 원본 자막을 덮어쓰지 않았는가
   - 오디오가 꺼져 있거나 한쪽만 들리지 않는가
   - 컷 경계가 말 중간을 자르지 않는가
   - 자막과 발화가 크게 어긋나지 않는가

4. 콘텐츠 위험
   - 근거 없는 단정이 있는가
   - 제목/썸네일 방향이 본문과 맞는가
   - 채널 톤과 맞지 않는 과장이나 비난이 있는가

## 게이트

다음 조건을 모두 통과해야 업로드 판단 단계로 넘긴다.

1. 5단계 컨트롤링 아이디어와 완성본 내용이 연결되어 있다.
2. 원본 영상과 원본 자막을 훼손하지 않았다.
3. 오디오, 자막, 컷 흐름의 치명적 문제가 없다.
4. 제목/썸네일 방향이 본문 내용과 맞는다.
5. 사용자 최종 승인이 필요하다고 표시되어 있다.
6. 검토한 버전이 `CURRENT.json`과 일치하고 원본·렌더 증거가 구분되어 있다.
7. 보존한 검수 미디어가 원본 자산 목록이나 현재본 렌더 근거에서 추적된다.

## 중단 조건

- 기준 기획서 없이 완성본만 보고 좋다고 판단하라는 요청이면 멈춘다.
- 오디오가 꺼졌거나 원본 참조가 깨진 상태면 업로드 가능 판정을 하지 않는다.
- 제목/썸네일이 본문과 다른 약속을 하면 멈추고 수정 필요로 표시한다.
- Premiere나 YouTube Studio에서 직접 확인하지 않았으면 앱 검증 완료라고 쓰지 않는다.
- 현재본 포인터와 실제 검토 영상 버전이 다르면 업로드 가능 판정을 하지 않는다.
- 변경 없는 재검수에서 새 캡처·오디오·러프컷을 만들려고 하면 멈춘다.

## 다음 단계 전달물

사용자에게 현재 검토 버전, 통과·실패 항목, 수정 필요 구간, 사용한 원본 `asset_ids`,
버전별 `render_evidence`, 남은 위험과 최종 승인 필요 항목을 넘긴다.

## AI가 확정하지 말 것

- 최종 업로드 여부
- 최종 제목/썸네일
- 영상의 최종 재미 판단
- 법적/정책적 안전 확정
- Premiere 또는 YouTube Studio 검증 완료
