# 김실버 채널 기획

이 스킬은 조사된 소재를 김실버 채널에 맞는 영상 기획으로 바꾼다.

## 김실버 채널의 기본 관점

김실버 채널은 단순 게임 리뷰보다 다음 방향이 잘 맞는다.

- 좋아했던 게임에게 실망한 유저의 감정
- 게임 구조를 보는 개발자 시선
- 과금, 운영, 매칭, 성장 구조가 유저 경험을 어떻게 바꾸는지
- 직접 플레이로 느낀 감정과 시스템 분석의 연결

## 입력

- 게임명
- 조사 자료
- 직접 플레이 여부
- 사용 가능한 영상/자막/대본
- 원하는 영상 톤

## 작업 순서

1. 소재의 핵심 갈등을 찾는다.
2. 김실버가 말할 수 있는 관점을 정한다.
3. 시청자가 클릭할 이유를 정리한다.
4. 영상의 핵심 주장을 한 문장으로 만든다.
5. 도입, 전개, 결론의 흐름을 잡는다.
6. 제목/썸네일 방향을 제안한다.

## 출력 형식

```markdown
## 영상 기획안

핵심 주장:

시청자가 클릭할 이유:

김실버 관점:

## 영상 흐름

1. 도입:
2. 문제 제기:
3. 직접 경험:
4. 구조 분석:
5. 결론:

## 제목/썸네일 방향

- 검색형:
- 궁금증형:
- 감정형:
```

## 주의

- 플레이하지 않은 내용을 단정하지 않는다.
- 감정적 비판만으로 끝내지 않는다.
- 개발자 의도를 확정적으로 말하지 않는다.
