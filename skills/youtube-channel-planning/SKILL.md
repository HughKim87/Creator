# 채널 기획

이 스킬은 1단계 소재 조사 결과를 대상 채널에 맞는 영상 콘셉트 후보로 바꾼다.
AI는 후보와 근거를 정리하고, 최종 콘셉트와 제목/썸네일은 사용자가 확정한다.

## 대상 채널의 기본 관점

대상 채널은 단순 게임 리뷰보다 다음 방향이 잘 맞는다.

- 좋아했던 게임에게 실망한 유저의 감정
- 게임 구조를 보는 개발자 시선
- 과금, 운영, 매칭, 성장 구조가 유저 경험을 어떻게 바꾸는지
- 직접 플레이로 느낀 감정과 시스템 분석의 연결
- 빠른 소식보다 겪어본 유저의 구조 해설

## 입력

- 1단계 소재 조사 산출물
- 사용자가 선택한 게임 또는 후보군
- 1단계에서 표시된 약한 근거와 보류 이유
- 직접 플레이 여부와 사용 가능한 자료
- 원하는 영상 톤 또는 피하고 싶은 톤

## 작업 절차

1. 소재의 핵심 갈등을 정리한다.
   - 유저 기대와 실제 경험의 차이
   - 운영, 과금, 성장, 매칭, 업데이트, 밸런스 문제
   - 지금 시점에 다시 말할 이유

2. 채널 관점 후보를 만든다.
   - 개발자 시선
   - 실망한 유저 시선
   - 구조 해부 시선
   - 직접 플레이 체험 시선

3. 시청자 클릭 이유를 분리한다.
   - 검색형: 이미 궁금해하는 주제
   - 궁금증형: 모르는 사람도 누를 질문
   - 감정형: 공감, 분노, 배신감, 허탈감

4. 영상 핵심 주장 후보를 2~3개 만든다.
   - 각 주장은 근거와 위험을 함께 쓴다.
   - 근거가 약한 주장은 보류로 표시한다.

5. 제목/썸네일 방향을 제안한다.
   - 제목은 정확하고 짧게 쓴다.
   - 중요한 단어를 앞에 둔다.
   - 썸네일은 누구에게 보일지 먼저 정한다.
   - 제목/썸네일이 영상 내용과 다르면 폐기한다.

## 게이트

다음 조건을 모두 통과해야 3단계 대본 구성으로 넘긴다.

1. 1단계 소재 조사 산출물을 기준 입력으로 사용했다.
2. 핵심 주장 후보가 2개 이상 있고, 각각 근거와 위험이 있다.
3. 채널 관점과 시청자 클릭 이유가 분리되어 있다.
4. 제목/썸네일 방향이 영상 내용과 맞는다.
5. 사용자가 최종 콘셉트를 승인해야 한다고 표시되어 있다.
6. 플레이하지 않은 내용과 개발자 의도를 단정하지 않았다.

## 중단 조건

- 1단계 소재 조사 없이 콘셉트를 만들라고 하면 멈추고 기준 입력을 요청한다.
- 직접 플레이 여부가 중요한 주장인데 확인되지 않았으면 보류한다.
- 제목/썸네일이 영상에서 다루지 않을 내용을 약속하면 폐기한다.
- 사용자가 채널 톤이나 관점을 거절하면 같은 방식으로 재생성하지 않고 조건을 다시 묻는다.

## AI가 확정하지 말 것

- 최종 콘셉트
- 영상 핵심 메시지
- 최종 제목과 썸네일
- 진행자가 실제로 경험했다는 표현
- 개발자 의도
- 논란의 옳고 그름

## 좋은 요청 예시

```text

운영/과금/성장 구조 관점, 실망한 유저 관점, 직접 플레이 관점으로 나눠서 보고,
각 후보마다 핵심 주장, 클릭 이유, 근거, 위험을 표시해.

```
