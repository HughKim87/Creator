# 게임 트렌드 리서치

이 스킬은 단순 인기 게임 순위가 아니라, 유튜브 영상으로 만들었을 때 클릭될 가능성이 있는 게임 소재를 찾는다.

## 입력

- 조사할 기간
- 대상 플랫폼
- 채널 성향
- 제외할 게임이나 장르

## 조사 항목

1. 유튜브 수요
   - 최근 조회수
   - 반복 등장하는 제목 키워드
   - 큰 채널과 작은 채널의 성과 차이

2. 방송 플랫폼 수요
   - 치지직
   - SOOP
   - 통합 랭킹
   - 1일/1주일 변화

3. 커뮤니티/뉴스 이슈
   - 출시
   - 업데이트
   - 논란
   - 과금
   - 운영
   - 유저 이탈

4. 채널 적합도
   - 김실버가 직접 플레이하거나 설명할 수 있는가
   - 개발자 시선이나 구조 해부가 가능한가
   - 감정선이 있는가

## 출력 형식

```markdown
## 게임 영상 소재 후보

수집 기준:
- 기간:
- 확인한 데이터:

| 순위 | 게임 | 현재 이슈 | 클릭 수요 | 방송 수요 | 채널 적합도 | 판단 |
|---|---|---|---|---|---|---|

## 상위 후보 분석

### 1. 게임명

- 왜 지금 뜨는가:
- 사람들이 궁금해하는 것:
- 이미 많은 영상 각도:
- 김실버 채널의 차별화 각도:
- 추천 제목 방향:

## 제외/주의 후보
```

## 주의

- 단순 랭킹만 제공하지 않는다.
- 왜 영상 소재가 되는지까지 설명한다.
- 근거가 부족하면 부족하다고 표시한다.
