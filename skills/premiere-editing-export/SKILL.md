# 프리미어 편집 자료 생성

이 스킬은 분석된 컷리스트를 프리미어에서 사용할 수 있는 자료로 바꾼다.

## 핵심 원칙

- 원본 영상을 복사하지 않는다.
- 원본 파일 이름을 바꾸지 않는다.
- 원본 파일 경로를 그대로 참조한다.
- 오디오를 비활성화하지 않는다.
- 사용자가 이해할 수 있는 짧은 사용 방법을 함께 만든다.

## 입력

- 원본 영상 경로
- 컷리스트
- 원하는 산출물 형식
- 프리미어 버전 또는 사용 가능한 가져오기 방식

## 산출물 선택

| 형식 | 용도 | 주의 |
|---|---|---|
| CSV | 사람이 확인하기 쉬운 컷리스트 | 프리미어 자동 시퀀스는 아님 |
| EDL | 간단한 컷 시퀀스 가져오기 | 파일 연결을 다시 해야 할 수 있음 |
| XML | 더 풍부한 프리미어 시퀀스 | 형식 오류 검증 필요 |
| JSX | 프리미어 내부 자동화 | 실행 위치가 불명확하면 쓰지 않음 |
| 러프컷 mp4 | 컷 흐름을 눈으로 확인하는 초안 영상 | 초안일 뿐 최종 편집본이 아님. 원본은 그대로 두고 새 파일 생성 |

기본값:
- 사용자가 잘 모르면 EDL 또는 XML을 우선한다.
- JSX는 사용자가 실행 방법을 알고 있을 때만 사용한다.
- "초안 보여줘", "먼저 붙여서 확인하고 싶다"면 러프컷 mp4를 만든다.

## 러프컷 초안 생성

컷리스트를 실제 영상으로 이어붙여 흐름을 확인한다.

```bash
python3 skills/premiere-editing-export/scripts/make_roughcut.py "원본.mkv" 컷리스트.csv 출력.mp4
```

- 컷리스트.csv: `시작,끝[,라벨]` 한 줄씩 (SS/MM:SS/HH:MM:SS)
- 출력은 기존 파일을 덮어쓰지 않는다 (존재 시 중단)
- 재인코딩 방식이라 컷 경계가 정확하다. 화질 조정은 `--crf`(낮을수록 고화질)
- 산출물은 `크아_컷편집_러프` 같은 작업 폴더의 `generated/` 하위에 둔다

## 출력 형식

```markdown
## 생성 파일

- 컷리스트:
- 프리미어 자료:
- 사용 방법:

## 사용 방법

1. 프리미어에서 `파일 > 가져오기`
2. 생성된 파일 선택
3. 연결 창이 뜨면 원본 영상 선택
4. 오디오가 켜져 있는지 확인
```

## 검수 항목

- 원본 경로가 맞는가
- 시퀀스가 누락되지 않았는가
- 오디오가 포함되어 있는가
- 컷 시작/끝 시간이 맞는가
- 사용자가 제공한 원본을 훼손하지 않았는가
