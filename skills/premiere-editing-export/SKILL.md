# 프리미어 편집 자료 생성

이 스킬은 7단계 편집 자료 생성을 담당한다.
목표는 최종 영상을 자동으로 완성하는 것이 아니라, 사용자가 Premiere에서
바로 이어서 다듬을 수 있는 편집 준비 패키지를 만드는 것이다.

## 핵심 원칙

- 원본 영상을 복사하지 않는다.
- 원본 파일 이름을 바꾸지 않는다.
- 원본 파일 경로를 그대로 참조한다.
- 오디오를 비활성화하지 않는다.
- 사용자가 이해할 수 있는 짧은 사용 방법을 함께 만든다.
- 완성본 자동화보다 `원본 + 후보클립 + 연결 시퀀스` 구조를 우선한다.

## 환경 전제 (사용자 편집 환경 — 영상 무관, 항상 적용)

사용자는 Premiere Pro **CS6**를 쓴다.

- **mkv 원본은 편집 전에 mp4로 무손실 remux한다.** CS6가 mkv를 지원하지 않아 미디어 오프라인이 난다. `tools/remux_mkv_to_mp4.bat`(재인코딩 없음)로 변환한 mp4를 원본 경로로 참조한다.
- **CS6는 FCP7 XML 오디오를 L/R 링크 모노 2트랙으로 가져온다(알려진 제약, 해결 불가).** 이 스크립트가 그 구조에 맞춰 오디오를 분해한다. 편집엔 지장 없고 볼륨만 2회 조정하면 된다 — 재시도하지 말 것.

## 입력

- 원본 영상 경로
- 6단계 후보지도와 사용자 승인된 대표 후보
- 최신 기준 컷리스트
- 원하는 산출물 형식
- 프리미어 버전 또는 사용 가능한 가져오기 방식

6단계 후보지도 없이 XML, EDL, 러프컷을 만들지 않는다. 컷리스트가 있더라도 기준 기획서와 후보지도에서 파생된 최신본인지 확인한다.

## 7단계 하위 작업

| 하위 단계 | 목적 | 입력 | 출력 |
|---|---|---|---|
| 7A | 컷리스트 초안 생성 | 승인된 6단계 후보지도, 보존/압축 기준 | 컷리스트 초안, 경계 주의표 |
| 7B | 컷 경계 검증 | 컷리스트 초안, 원본, 자막, 필요한 도구 | 조정 제안, 수정 컷리스트 |
| 7C | 편집 자료 변환 | 승인된 컷리스트 | XML/EDL/CSV/러프컷, 사용 방법 |

`tools/synccheck`는 7B에서 말 중간 컷, 자막 어긋남, 시작/끝 경계 위험이 있을 때만 보조로 사용한다.
7C 이전에는 XML, EDL, 러프컷을 만들지 않는다.

## 산출물 선택

| 형식 | 용도 | 주의 |
|---|---|---|
| CSV | 사람이 확인하기 쉬운 컷리스트 | 프리미어 자동 시퀀스는 아님 |
| XML | 원본/후보클립/시퀀스를 함께 가져오는 기본 산출물 | Premiere에서 실제 가져오기 검증 필요 |
| EDL | 간단한 컷 시퀀스 가져오기 | 구조가 단순하고 파일 연결을 다시 해야 할 수 있음 |
| JSX | 프리미어 내부 자동화 | 실행 위치가 불명확하면 쓰지 않음 |
| 러프컷 mp4 | 컷 흐름을 눈으로 확인하는 초안 영상 | 초안일 뿐 최종 편집본이 아님. 원본은 그대로 두고 새 파일 생성 |

기본값:
- 사용자가 잘 모르면 XML을 우선하고, 실패 대비로 EDL/CSV를 함께 둔다.
- JSX는 사용자가 실행 방법을 알고 있을 때만 사용한다.
- "초안 보여줘", "먼저 붙여서 확인하고 싶다"면 러프컷 mp4를 만든다.

## Premiere XML 편집 패키지 생성

컷리스트를 Final Cut Pro 7 XML(`xmeml`) 형태로 만들어 Premiere의
`파일 > 가져오기`에서 열 수 있게 한다. 이 방식은 EDL보다 풍부해서
원본 참조, 후보 클립, 연결 시퀀스를 함께 넣는 데 적합하다.

```bash
<python> skills/premiere-editing-export/scripts/make_premiere_xml.py "원본.mkv" 컷리스트.csv premiere_export/편집.xml --guide premiere_export/편집_사용방법.md
```

- 컷리스트.csv는 `시작,끝[,라벨]` 또는 `시작/끝/구간명` 헤더 형식을 지원한다.
- XML은 기존 파일을 덮어쓰지 않는다 (존재 시 중단).
- XML 내부 구조는 `00_원본`, `01_후보클립`, `02_시퀀스`를 기본으로 한다.
- MKV 연결이 불안정하면 원본을 편집용 중간 파일로 따로 변환한 뒤 같은 컷리스트로 다시 만든다.
- XML 가져오기가 실패하면 EDL을 대체 경로로 사용한다.

## 러프컷 초안 생성

컷리스트를 실제 영상으로 이어붙여 흐름을 확인한다.

```bash
<python> skills/premiere-editing-export/scripts/make_roughcut.py "원본.mkv" 컷리스트.csv 출력.mp4
```

- 컷리스트.csv: `시작,끝[,라벨]` 한 줄씩 (SS/MM:SS/HH:MM:SS)
- 출력은 기존 파일을 덮어쓰지 않는다 (존재 시 중단)
- 재인코딩 방식이라 컷 경계가 정확하다. 화질 조정은 `--crf`(낮을수록 고화질)
- 산출물은 `workspace/outputs/07_edit_export/` 아래에 둔다.

## 출력 형식

```markdown
## 산출물 상태

- 상태: 산출물
- 생성일:
- 생성 목적: 7단계 편집 자료 생성
- 기준 입력: 승인된 6단계 후보지도, 최신 컷리스트
- 사용한 원본:
- 사용한 기준 문서:
- 생성 도구:
- 검증 수준: Parsed, Structure-validated, Tool-validated 중 하나
- 다음 단계 사용 가능 여부: 사용자 컷 흐름 승인 후 가능
- 사용자 승인 필요: 예
- 사용 금지 조건: 기준 컷리스트나 원본 경로가 바뀐 경우

## 생성 파일

- 컷리스트:
- 프리미어 XML:
- 보조 EDL/CSV:
- 사용 방법:

## 사용 방법

1. 프리미어에서 `파일 > 가져오기`
2. 생성된 파일 선택
3. `00_원본`, `01_후보클립`, `02_시퀀스`가 들어왔는지 확인
4. 연결 창이 뜨면 원본 영상 선택
5. 오디오가 켜져 있는지 확인
```

## 검수 항목

- 원본 경로가 맞는가
- 시퀀스가 누락되지 않았는가
- 오디오가 포함되어 있는가
- 컷 시작/끝 시간이 맞는가
- 사용자가 제공한 원본을 훼손하지 않았는가

## 게이트

다음 조건을 모두 통과해야 8단계 최종 검수로 넘긴다.

1. 6단계 후보지도에서 승인된 후보만 사용했다.
2. 7A/7B를 거친 최신 컷리스트이며 기준 파일명이 기록되어 있다.
3. 원본 경로와 remux 경로가 구분되어 있다.
4. XML/EDL/CSV/러프컷의 검증 수준이 표시되어 있다.
5. Premiere에서 직접 열어보지 않았으면 `App-validated`라고 쓰지 않는다.
6. 사용자가 컷 흐름을 승인해야 한다고 표시되어 있다.

## 중단 조건

- 6단계 후보지도 없이 편집 자료 생성을 요청받으면 멈춘다.
- 원본 경로가 불명확하거나 MKV remux 여부가 불명확하면 멈춘다.
- 컷 경계 검증 없이 XML을 확정본처럼 만들려고 하면 멈춘다.
- Premiere에서 열어보지 않았는데 사용 가능 확정이라고 쓰게 될 때 멈춘다.

## AI가 확정하지 말 것

- 최종 컷 흐름
- Premiere 사용 가능 확정
- 업로드용 최종본
- 컷 경계 최종 스냅
- 오디오 믹스 완료
