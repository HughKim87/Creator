# 대사 기반 기획

이 스킬은 워크플로우 **5단계 대사 기반 기획**을 라우팅한다.
상세 절차의 단일 기준은 `planning_research/planning_stage_spec_2026-07-06.md`다.
이 파일은 스킬 계약만 담당하며, 상세 규격을 복사하지 않는다.

## 입력

- 원본 영상
- 4단계에서 전달된 안정된 `source_id`와 원본 시간 기준
- 원본 자막 또는 자동 전사 원본
- 4단계 `subtitle-cleanup` 산출물과 타임코드 신뢰도
- 정리 자막 사용 여부
- 이전 산출물 사용 여부: 기본값 `사용 안 함`
- 사용자가 확인한 톤, 메시지, 제외 조건

원본 자막이나 전사 기준이 없으면 5단계를 시작하지 않고 4단계 자막 정리로 돌린다.

## 출력

5단계 기획서는 아래 항목을 포함한다.

- 산출물 상태
- `source_id`, 기준 원본 지문, 원본 시간 기준
- `baseline_version`, `changed_ranges`, `supersedes`, `current_pointer`
- 기준 입력
- 통독 메모 요약
- 인용 로그
- 기능 코드북
- 후보 메시지 비교
- 컨트롤링 아이디어 확정
- 대사 스파인
- 감정 아크
- 포함/제외 기준
- 반례·약점
- 6단계 검증 브리프
- G1/G2/G3/G4 통과표

## 게이트

다음 조건을 모두 통과해야 6단계 영상 분석으로 넘긴다.

1. 컨트롤링 아이디어의 핵심 조각이 원본 대사 인용으로 추적된다.
2. 반례 또는 약점이 기록되어 있다.
3. 대사 스파인만 읽어도 시작, 변화, 결말이 보인다.
4. 각 비트를 뺐을 때 잃는 이야기 기능이 명확하다.
5. 화면 검증 질문이 비트별로 붙어 있다.
6. 사용자가 컨트롤링 아이디어를 승인해야 한다고 표시되어 있다.
7. 인용·비트·검증 질문이 모두 같은 `source_id`의 원본 시간으로 추적된다.

## 중단 조건

- 원본 영상이나 기준 자막이 불명확하다.
- 4단계 정리 자막의 의미 변경 위험이 해결되지 않았다.
- 컷리스트, XML, 러프컷이 기획 기준을 끌고 있다.
- 메시지가 원본 대사보다 해석에 의존한다.
- 반박 대사를 무시해야만 컨트롤링 아이디어가 성립한다.
- 화면 검증 없이 바로 컷 취사로 넘어가야만 성립한다.

## 다음 단계 전달물

6단계 `gameplay-video-analysis`에는 아래만 넘긴다.

- 컨트롤링 아이디어
- `source_id`, 기준 원본 지문, 원본 시간 기준
- 대사 스파인
- 감정 아크
- 포함/제외 기준
- 비트별 화면 검증 질문
- 문장 단위로 보존할 구간
- 반복 후보 중 비교해야 할 장면
- 위험 표시: 사망 화면, 결과 반응, 앞뒤 보존 필요 구간
- 기존 원본 자산 목록 경로와 재사용 가능한 `asset_ids`

## AI가 확정하지 말 것

- 최종 컨트롤링 아이디어
- 최종 메시지
- 컷 경계
- 컷리스트
- XML, EDL, 러프컷
- 업로드 판단

## 좋은 요청 예시

```text
원본 자막과 4단계 정리 자막 기준으로 5단계 대사 기반 기획서를 만들어줘.
컨트롤링 아이디어 후보를 비교하고, 인용 로그와 반례, 대사 스파인, 6단계 검증 브리프까지 작성해줘.
컷리스트나 XML은 만들지 마.
```

```text
이 자막에서 영상 메시지를 억지로 만들지 말고, 원본 대사로 추적되는 컨트롤링 아이디어만 후보로 정리해줘.
화면으로 확인해야 할 질문은 6단계 브리프로 넘겨줘.
```
