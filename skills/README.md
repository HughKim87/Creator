# Skills Index

이 폴더는 김실버 유튜브 작업에 사용하는 독립 스킬을 관리한다.

## 현재 운영 스킬과 보조 스킬

| 스킬 | 단계 | 역할 | 상태 |
|---|---:|---|---|
| `game-trend-research` | 1 | 소재 조사 | 1차 보강 완료 |
| `youtube-channel-planning` | 2 | 채널 기획 | 1차 보강 완료 |
| `youtube-script-planning` | 3 | 대본 구조, 주장 흐름, 장면 목적 | 1차 신설 완료 |
| `subtitle-cleanup` | 4 | 자막 생성/정리, 원문 보존, 타임코드 신뢰도 표시 | 1차 신설 완료 |
| `gameplay-video-analysis` | 6 | 화면 검증, 후보 지도, 7단계 인계 브리프 | 1차 보강 완료 |
| `video-watch` | 보조 | 영상 프레임 추출과 전사 보조 | 보조 유지. 6단계에서 호출 |
| `premiere-editing-export` | 7 | 컷리스트를 Premiere용 XML/EDL/CSV/러프컷으로 변환 | 1차 보강 완료 |
| `final-video-review` | 8 | 최종 검수표, 수정 필요 목록, 업로드 전 확인 | 1차 신설 완료 |

## 스킬 보강 공통 기준

각 스킬은 아래 항목을 가져야 한다.

1. 입력
2. 출력
3. 게이트
4. 중단 조건
5. 다음 단계 전달물
6. AI가 확정하지 말 것
7. 좋은 요청 예시

## 보강 순서

1. `game-trend-research` - 1차 보강 완료
2. `youtube-channel-planning` - 1차 보강 완료
3. `youtube-script-planning` - 1차 신설 완료
4. `subtitle-cleanup` - 1차 신설 완료
5. 5단계 기획 규격과 워크플로우 동기화 - 완료
6. `gameplay-video-analysis` - 1차 보강 완료
7. `premiere-editing-export` - 1차 보강 완료
8. `final-video-review` - 1차 신설 완료

## 현재 빠진 스킬

현재 1~8단계의 1차 스킬 또는 규격은 모두 존재한다.

## 삭제된 구 자료

과거 구버전 `.skill` 파일은 현재 파일시스템에 남아 있지 않다. 삭제된 구 스킬 폴더도 기준 자료로 사용하지 않는다.

필요하면 남아 있는 운영 스킬과 5단계 기획 규격을 기준으로 추가 보강한다.
