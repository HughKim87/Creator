# Skills Index

이 폴더는 김실버 유튜브 작업에 사용하는 독립 스킬을 관리한다.

## 현재 운영 스킬

| 스킬 | 역할 | 상태 |
|---|---|---|
| `game-trend-research` | 1단계 소재 조사 | 유지. 개선 필요 |
| `youtube-channel-planning` | 2단계 채널 기획 | 유지. 개선 필요 |
| `gameplay-video-analysis` | 6단계 화면 검증, 후보 지도, 7단계 인계 브리프 | 유지 |
| `video-watch` | 영상 프레임 추출과 전사 보조 | 유지 |
| `premiere-editing-export` | 컷리스트를 Premiere용 XML/EDL/CSV/러프컷으로 변환 | 유지. 6단계 산출물과 연결 기준 보강 필요 |

## 현재 빠진 스킬

| 단계 | 필요 작업 |
|---:|---|
| 3 | 대본 구성 규격 또는 스킬 신설 |
| 4 | 자막 생성/정리 규격 또는 스킬 신설 |
| 8 | 최종 검수 규격 또는 스킬 신설 |

## 삭제된 구 자료

과거 구버전 `.skill` 파일은 현재 파일시스템에 남아 있지 않다. 삭제된 구 스킬 폴더도 기준 자료로 사용하지 않는다.

필요하면 남아 있는 운영 스킬을 기준으로 새로 보강한다.
