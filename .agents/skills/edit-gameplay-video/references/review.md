# 검수 실행과 반복 수정 방지

Creator R05~R09·R11~R18의 실행 안내다. 규칙·합격 조건의 별도 정본이 아니다. 관찰 문구의 존재는 사실 확인의 증명이 아니다.

## 컷 계획 전

원본에서 장소·목표·단계·인물·생존 상태 변화 목록을 만든다. 모든 후보마다 다음을 실제 anchor 또는 미확인으로 연결한다.
- 왜 행동하는가? 목표·결심을 시청자가 아는가?
- 누구와 어디에 있는가? 직전 사건 뒤 어떻게 이 상태가 됐는가?
- 피격·실패·결과가 화면에 있는가, 발화/로그로만 추론한 것인가?
- 다음 지시어·대답·웃음이 전제하는 대상은 무엇인가?
- 무발화 화면에 이동·몸짓·긴장·결과 확인 기능이 있는가?
- 장면이 빠지면 이해나 웃음이 사라지는가, 이미 전달한 반복인가?

처음부터 특정 주제로 검색한 결과만 모으지 않는다. 인과를 이유로 긴 source block 전체를 유지하지 말고 anchor 사이를 다시 편집한다.

## 편집 뒤 순차 점검

1. 최종 전사를 순서대로 읽어 지시어·대답·정정·주제 전환의 전제 대상을 찾는다. 전사로 화면 상태를 확인했다고 기록하지 않는다.
2. 원본 전환 목록과 최종 scene을 대조한다. 컷 앞/뒤 위치·생존·동료·목표, 차이를 설명하는 anchor, 생략 이유를 기록한다. 설명 없는 변화는 bridge 복원·후행 사건 제외·다른 후보 선택으로 해결한다.
3. 실제 A/V 생략 범위를 관찰한다. 필수 원인·이동·행동 결과·반응을 대기로 오분류하지 않았는지 보고 editorial-check로 anchor·생략 coverage·누적 feedback을 검사한다. 이 검사는 설명의 진실을 판정하지 않는다.
4. retained 발화는 clip별로, 접합은 앞뒤를 함께 재전사한다. 원본 단어 시각과 오디오 컷을 비교해 단어 내부 절단·약한 말끝·다음 발화 파편·인접 거짓 시작을 찾는다. ASR이 잡은 침묵·웃음·0길이 단어는 원본으로 판정한다.
5. 가능하면 원본/편집 경계를 정상 속도 A/B로 듣고 본다. 불가능하면 프레임·파형·재전사 결과와 한계를 적고 최종 발화 품질은 미검증이다. 같은 모델 재전사는 독립 인식/직접 청취가 아니다.
6. 남긴 무발화의 화면 기능을 대조한다. 반복 버튼 유지·로딩은 압축하되 준비·접근·결과·반응은 살린다. 시작과 꼬리의 불필요한 대기도 확인한다.
7. 편집본 오디오로 SRT를 생성하고 전 cue의 표기·화자·싱크를 점검한다. 정정 대사를 삭제해 틀린 추측만 남기지 않는다. 외국어·이름은 원본 근거로 해소한다. 표시 시 글꼴 폭·줄 수·핵심 행동 가림을 확인한다.
8. 최신 전체 후보를 정상 속도로 연속 검수할 수 있으면 인과·공간 / 템포·반복 / 화면·음성 경계를 각각 기록한다. 못 했으면 not_run을 유지한다.

## 행동 평가 사례

| 원본 상황 | 기대 판단 | 실패 징후 |
|---|---|---|
| 역할 결심과 장비 준비 | 실제 결심·준비·출발 연결 | 설명 카드로 역할 창작/결심 생략 |
| 출발 뒤 다시 기지 | 복귀 원인 확인 또는 해당 출발 제외 | 설명 없이 두 출발 연결 |
| 아군과 만난 후 혼자 다운 | 헤어진 변화·위험·다운 확인, 약하면 다른 사건 | 고립 원인 생략/이동 전체 복원 |
| 본인 다운 뒤 동료 소생 | 재기·재출격·합류 선행 확인 | 생존 상태 점프 |
| 질문 뒤 몸을 확인하고 총을 흔듦 | 질문·무발화 몸짓 답변·인사 보존 | silence detector가 몸짓 삭제 |
| 여러 번 상호 소생 | 새 실패·역할 교대·반응 보존, 같은 대기 압축 | 모든 대기 보존/결과만 나열 |
| 더듬은 뒤 정정 | 완결된 의미와 실제 연결 보존 | 조사/단어 파편·틀린 첫 표현만 잔존 |
| 한 곳의 상태 점프 피드백 | 전편 같은 전환 유형 재검토 | 지적 시각만 수정 |
| ASR·디코딩·프레임만 성공 | 그 범위 보고, 청취·의미 not_run | “말 안 끊김/최종 검수 완료” |

문구가 존재하는지 검사하는 테스트로 편집 행동 평가를 대신하지 않는다. 실제 원본·컷·출력 변화를 대조한다. 알려진 사례 회귀와 다른 게임의 새 평가를 구분하며 실제 미시험이면 재미 개선·일반화가 입증됐다고 보고하지 않는다.

## 피드백

record-feedback으로 원본 anchor와 함께 누적한다. 위치/생존 전환/발화 절단/반복/자막 등 유형을 정하고 같은 유형의 영향 범위를 재탐색한다. exact baseline diff로 positive lock·untouched를 보존한다. 새 editorial fingerprint에 검수와 자막을 결속한다. 해결 문구로 필수 anchor나 원래 의미를 대체하지 않는다.
## 후편집 검수 연결

대본에 작업 자료를 맞추는 제작에서는 [목적별 경로](../../../../extension/docs/domain/youtube/VIDEO_PURPOSE_WORKFLOWS.md)의 자료·시기·상태 대조를 함께 적용한다. ‘초기 시도’에 최종본을 붙이거나 새 실패 강조로 무관한 도입까지 바꾸는 반례를 확인한다. 대본·음성 바이트 보존과 화면 의미 보존은 서로 다른 확인이다. 목록·정지 관찰·동작 재생의 확인 수준을 구분하고, 이미 관찰한 자료는 변경 영향이 없으면 재사용한다. 확인된 동작 원본을 찾지 못한 경우 정지 표본만으로 회전·동작이 없다고 단정하지 않는다.

컷 이후 레이어·아웃트로는 [후편집 실행](post-production.md)의 최종 검사 절을 추가 적용한다. 컷 근거 검사를 레이어 가림·색·최종 오디오·결합 SRT 검사의 대체물로 쓰지 않는다. 기술 검사와 실제 A/V 관찰 결과를 구분한다.
