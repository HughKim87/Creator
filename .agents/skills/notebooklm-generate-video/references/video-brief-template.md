# NotebookLM 동영상 브리프 템플릿

- 목적: 근거에서 성립하는 질문·진행·답변을 생성 지시와 완성 영상 검수에 연결한다.
- 읽는 시점: 복잡한 구성 또는 도입·결론의 연결을 설계할 때.
- 책임: 생성 스킬은 지시를 작성하고 coordinator의 기존 내용 검수가 실제 반영을 확인한다.
- 상태: 활성 제작 참고. 직접 녹음용 확정 대본이나 새 완료 게이트가 아니다.
- 관련 권위: ../SKILL.md, coordinate-video-production의 영상 내용 검수.

## 질문과 답변 연결

브리프 작성 전에 시청자의 질문 한 문장, 답할 수 있는 범위, 사용한 출처를 정한다. 필요한 경우 도입을 질문형·비교형·근거 제시형 중 실제 자료가 지지하는 방식으로 비교한다. 낚시성 위기·직접 해보지 않은 경험·확인하지 않은 성과를 만들지 않는다. 선택 이유는 기존 작업 근거에 기록한다.

`클릭 후 기대할 답 → 초반에 확인할 근거 → 본문의 각 진행 → 마지막 선택 기준·답변 → 남는 한계`를 연결한다. 게임 실황을 설명 영상의 고정 형식으로 바꾸지 않는다. 채널 말투 요청이 있을 때만 [말투 적용](../../youtube-title-thumbnail/references/channel-voice.md)을 참조한다.

완성 후 기존 내용 검수에서 실제 첫 질문·근거 장면·답변 위치를 SRT와 화면에 연결한다. 프롬프트 입력만으로 반영 완료라 하지 않는다. 약속이 회수되지 않으면 실제 내용에 맞게 약속을 줄이거나 승인된 수정 범위에서 보정한다. 새 단계·별도 승인·전체 재생성의 필수 조건을 만들지 않는다. 구조 아이디어 참고: [yt-script](https://github.com/Jakeschincariol/youtube-agent-skill/tree/main/skills/yt-script).

## AI 호스트 집중 프롬프트

```text
[대상 시청자]를 위한 약 [목표 길이] [언어] 설명 영상으로 구성하세요.

오프닝:
- [시청자가 궁금해할 질문 또는 문제]로 시작합니다.
- 초반에 [실제 출처·비교 화면·확인 가능한 근거]를 보여주고 [답할 범위]를 안내합니다.

본문 순서:
1. [핵심 항목 1]
2. [핵심 항목 2]
3. [비교 대상과 선택 기준]
4. [비용·속도·품질·사용 난이도]
5. [실무 상황별 추천과 첫 질문에 대한 명시적인 답]

각 항목은 [첫 질문을 어떻게 진행시키는지]와 [보여줄 표·사례·화면]을 연결합니다.
마지막에는 [답변]과 [근거가 부족해 단정하지 않을 범위]를 구분합니다.

공식 사실, 공식 벤치마크, 커뮤니티 체감, 분석자의 해석을 명확히 구분하세요. 숫자는 평가 조건과 함께 설명하고, 소스에 없는 단정과 과장을 피하세요. 마지막에는 시청자가 바로 적용할 수 있는 선택 기준으로 마무리하세요.
```

## 맞춤 시각 스타일 프롬프트

```text
16:9 유튜브 [주제 분야] 설명 영상입니다.
[배경색]을 기본으로 [강조색]을 사용합니다.
[비교 대상 A/B/C]는 각각 [색상 A/B/C]로 일관되게 구분합니다.
큰 비교표, 인포그래픽, 흐름도를 중심으로 구성하고 한 화면에는 핵심 문구 1~2개만 크게 표시합니다.
작은 글자, 과도한 장식과 불필요한 캐릭터를 피하고 [원하는 분위기] 스타일로 만드세요.
```
