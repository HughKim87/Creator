# 게시 영상 타임스탬프·해시태그

목적: 기존 설명과 유효한 챕터를 보존하며 승인된 변경만 반영한다.
읽는 시점: 게시 영상의 타임스탬프·해시태그·설명 보완 요청.
책임: 이 스킬은 대상 확인·기존 설명 비교·승인된 Studio 반영을 담당하고, 로컬 챕터 생성·검증은 기존 전문 스킬을 사용한다.
상태: 활성. 현재 브라우저 API를 사용한다.
관련 권위: 현재 사용자 요청과 프로젝트의 외부 쓰기·자료 접근 경계.

## 범위와 도구

- 로컬 설명 초안·수동 업로드 가이드만 요청했다면 현재 프로젝트의 [prepare-youtube-upload](../prepare-youtube-upload/SKILL.md) 설명/챕터 모드로 연결해 채팅 또는 로컬 결과로 완료한다. 이 경우 Studio 저장을 하지 않는다.
- 게시물 수정은 현재 사용자가 지정한 exact 영상·변경 범위에서만 수행한다. 조회 범위를 채널 전체로 자동 확대하지 않는다. 총괄에서 전달한 단순 분석·생성 승인을 게시물 변경 승인으로 바꾸지 않는다.
- 브라우저는 현재 `mcp__cua_repl.js`의 문서와 지원되는 탭 탐색·화면 읽기·UI 조작 API를 사용한다. 초기화 전에는 도구 안내에 따라 `await cua.getState();` 한 번으로 문서를 읽는다. 지정 프로필은 [connect-chrome-profile](../connect-chrome-profile/SKILL.md)을 통해 검증하고 반환 탭을 재사용한다.
- 브라우저 문서가 제공하지 않는 내부 데이터 접근·임의 DOM 변경·비공개 요청을 실행하지 않는다. 로그인·권한 오류·지원 UI 부재는 관측한 경계까지만 보고한다. 이전 확장 도구명이나 특정 AI 패널은 필수 의존성이 아니다.

## 기존 설명과 후보

1. 채널·영상 ID를 현재 화면과 대조하고 기존 설명·길이·챕터·해시태그를 읽는다. 요청한 영상 목록이 없으면 처리할 대상을 먼저 특정한다.
2. 설명과 유효한 챕터는 보존한다. 타임스탬프 모양의 존재와 실제 유효한 챕터를 구분한다. 이미 완성된 항목은 다시 작성하지 않고 요청한 누락·오류만 보완한다.
3. 검증된 최종 영상 SRT가 있으면 현재 프로젝트 [prepare-youtube-upload](../prepare-youtube-upload/SKILL.md)의 「한국어 설명·검색 의도와 챕터」 절차와 `scripts/chapters.py`를 재사용한다. 원 영상의 주제/사건 전환을 확인해 한국어 제목을 쓴다. SRT·화면 등 근거가 없으면 시각을 추측하지 않고 필요한 자료 또는 확인 불가를 반환한다.
4. 챕터는 00:00 시작·최소 3개·오름차순·마지막을 포함한 각 구간 최소 10초인지 실제 영상 길이로 검증한다. 형식 통과는 실제 표시 보장이 아니다. 근거: https://support.google.com/youtube/answer/9884579?hl=ko (2026-10-23 확인).
5. 노래·짧은 영상·의미 있는 구분이 없는 영상에 챕터를 억지로 만들지 않는다. 분량당 고정 개수나 영어 어절 제한을 합격 기준으로 쓰지 않는다. 해시태그는 실제 내용과 관련된 것만 제안하며 개수·반복으로 성과를 보장하지 않는다.

## 반영과 검증

수정 전 기존 설명과 변경할 블록을 비교해 보존할 내용과 exact 변경을 확인한다. 게시물 쓰기가 현재 승인에 포함되지 않았으면 구체적인 변경안을 먼저 제공하고 해당 쓰기 직전에 승인을 요청한다. 이미 승인된 대상·범위는 반복 승인받지 않는다.

승인된 경우에만 현재 지원 UI로 해당 영상의 설명을 수정하고 저장한다. 저장 응답만으로 완료라 하지 않고 같은 영상의 설명을 다시 읽어 변경 블록과 보존 문구를 대조한다. 저장 결과가 불명확하면 재조회 전에 반복 저장하지 않는다. UI·권한 때문에 반영하지 못하면 초안과 미반영 상태를 반환한다.

결과는 영상별 변경/유지/미반영 항목과 실제 검증 범위로 보고한다. 자동 스케줄·채널 전체 일괄 수정·메타데이터 재작성·공개 범위 변경은 요청 범위 밖에서 실행하지 않는다.
