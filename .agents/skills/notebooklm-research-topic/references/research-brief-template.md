# Deep Research 조사 브리프 템플릿

아래 템플릿은 조사 주제에 맞게 채운 뒤 한 번에 제출한다. 대괄호 항목을 그대로 남기지 않는다.

```text
[기준일] 기준으로 [주제]를 [대상 시청자]용 [목표 길이] 한국어 영상으로 설명하기 위한 심층 리서치를 수행해 주세요.

조사 목표:
1. [핵심 질문 1]
2. [핵심 질문 2]
3. [비교 대상과 평가 관점]
4. [제품·요금제·플랫폼별 제공 범위]
5. [비용·속도·품질·사용 난이도에 따른 실무 추천]
6. 공식 발표, 도움말, 기술 문서, 가격 문서, 시스템 카드와 벤치마크를 우선 수집하고 각 수치의 평가 조건과 게시일을 기록합니다.
7. Reddit, Hacker News, 공식 개발자 포럼, GitHub 등에서 실제 사용자 경험을 수집합니다. 긍정·부정·상충 사례를 함께 포함하고 URL과 게시일을 기록합니다.
8. 영상에서 피해야 할 과장, 잘못된 비교, 제품별 제공 범위 혼동을 정리합니다.

결과는 한국어 구조화 보고서로 작성하고 모든 핵심 주장에 출처를 연결해 주세요. 공식 사실, 공식 벤치마크, 커뮤니티 체감, 해석·추론을 명확히 구분해 주세요.
```

## 출처 선택 체크

- 공식 1차 자료 3개 이상
- 커뮤니티·개발자 경험 3개 이상, 플랫폼 유형 2종류 이상
- 독립 벤치마크 또는 전문가 검증 1개 이상
- 보고서 자체 선택
- 주제와 직접 관련 없는 출처 제외

가져온 뒤에는 페이지 등록 수가 아니라 실제 사용 가능한 출처 수를 확인한다. 로딩 실패나 접근 오류가 난 URL은 실패 목록으로 분리한다.
