# NotebookLM 주제 리서치

NotebookLM 안에서 리서치를 수행하고, 다음 제작 단계가 사용할 수 있는 검수된 노트북을 준비한다. 외부 검색 결과를 NotebookLM 작업 결과처럼 대체하지 않는다.

## 입력 확정

다음 항목을 사용자 요청에서 추출한다. 빠진 항목은 결과를 바꾸지 않는 범위에서 합리적으로 보완한다.

- 조사 주제와 기준일
- 대상 시청자와 목표 영상 길이
- 반드시 답할 질문
- 비교 대상과 평가 관점
- 필요한 공식 자료와 커뮤니티 범위
- 결과 언어와 노트북 제목

복잡한 주제는 `references/research-brief-template.md`를 읽고 한 번의 구조화된 조사 프롬프트로 만든다.

## Chrome 연결 게이트

1. 브라우저 작업 전에 작업 기록의 `browser.profile_directory`와 `required_origin`으로 `$connect-chrome-profile`을 실행한다. 값이 없으면 각각 `Profile 4`와 `https://notebooklm.google.com`을 사용한다.
2. 연결 스킬이 `status: connected`를 반환할 때만 리서치를 시작하고, 반환된 Chrome 바인딩과 검증된 탭을 재사용한다.
3. 공식 프로필 진단과 프로필 대상 실행 경로가 끝나기 전에 사용자에게 프로필 메뉴 전환이나 확장 패널 준비를 요구하지 않는다.
4. 연결 스킬이 `needs_user` 또는 `unavailable`을 반환하면 그 결과를 그대로 기록하고 멈춘다. 다른 브라우저나 계정으로 우회하지 않는다.
5. 쿠키, 로컬 저장소, 전체 프로필 경로, 브라우저 ID, 확장 인스턴스 ID, 비밀번호 또는 계정 주소를 검사하거나 기록하지 않는다.
6. 기존 노트북을 사용할지 새 노트북을 만들지는 사용자의 명시된 범위에 따른다. 명시가 없으면 새 노트북을 만든다.

## Deep Research 실행

1. NotebookLM을 열고 대상 노트북을 확인한다.
2. 출처 검색 모드를 `Deep Research`로 바꾼다.
3. 구조화된 조사 프롬프트를 한 번 제출한다.
4. 다음 상태 변화를 관찰하며 기다린다.

   `계획 중 → 웹사이트 조사 중 → n/5단계 완료 → 보고서 작성 중 → Deep Research 완료`

5. 진행 표시와 `소스 탐색 중지`가 남아 있으면 같은 검색을 다시 제출하거나 중지하지 않는다.
6. 완료되기 전에는 출처 가져오기, 보고서 생성 반복, 동영상 생성을 시작하지 않는다.

## 출처 검수와 가져오기

완료 카드에서 `소스 보기`를 열고 보고서와 개별 출처를 검수한다. 자동 선택된 주요 출처를 그대로 신뢰하지 않는다.

가져오기 전 최소 품질 게이트:

- Deep Research 보고서가 선택되어 있다.
- 제품 발표, 도움말, API·가격 문서, 시스템 카드 등 공식 1차 자료가 3개 이상 선택되어 있다.
- 실제 사용 경험을 담은 커뮤니티·개발자 출처가 3개 이상이며, Reddit·Hacker News·개발자 포럼·GitHub·독립 전문가 분석 중 2종류 이상을 포함한다.
- 독립 벤치마크나 실무 검증 자료가 1개 이상 선택되어 있다.
- 공식 사실, 공식 벤치마크, 커뮤니티 체감, 분석자의 해석을 구분할 근거가 있다.
- 주제와 무관한 기사, 출처 없는 요약, 과장성 재가공 글은 선택 우선순위에서 제외한다.

게이트를 충족하도록 출처를 보강한 뒤 한 번만 가져온다.

## 처리 결과 검증

1. 모든 로딩 표시가 사라질 때까지 기다린다.
2. `발견`, `선택`, `등록`, `사용 가능`, `오류` 수를 서로 구분한다.
3. 오류 출처는 사용 가능한 근거로 세지 않는다.
4. 사용 가능한 공식 1차 자료와 커뮤니티 자료가 각각 하나도 없으면 대체 출처를 추가하고 한 번 재검증한다.
5. 노트북 제목을 주제가 드러나는 짧은 이름으로 바꾸고 저장 여부를 화면에서 확인한다.
6. 노트북 URL, 제목, 사용 가능 출처 수, 오류 출처 수와 유형, 충족한 출처 범주를 반환한다.

## 정지 조건

리서치 보고서와 출처가 준비된 시점에서 멈춘다. 동영상 개요, 오디오, 슬라이드, 썸네일, 자막, 수동 업로드 자료 준비는 별도 스킬의 책임이며, 실제 YouTube 업로드는 사용자가 직접 수행한다.

다음 중 하나면 사용자에게 상태와 필요한 조치만 알리고 멈춘다.

- `$connect-chrome-profile`이 공식 복구 절차 후 `needs_user` 또는 `unavailable`을 반환함
- Deep Research가 명시적 오류로 종료됨
- 공식 자료와 커뮤니티 자료의 최소 게이트를 대체 출처로도 충족하지 못함
- 유료 사용, 권한 변경, 공유 또는 게시가 필요함
