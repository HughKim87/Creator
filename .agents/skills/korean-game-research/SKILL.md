# 한국 신작 게임 리서치 (보조 자동화)

한국 게이머 커뮤니티와 게임 정보 사이트에서 **확정된** PC/모바일 신작 출시, 대형
업데이트, 사전예약 현황을 수집·정리하고, 중복을 제거한 뒤 **사용자 승인 후** 구글
캘린더에 등록한다.

- 영상 제작 1~8단계 파이프라인과 독립된 보조 스킬이다. 산출물 수요자는 사용자와
  사용자의 구글 캘린더다.
- 안전 규칙은 `PROJECT_RULES.md`를 따른다. 캘린더 등록은 외부 쓰기이므로
  `PROJECT_RULES.md`의 "외부 쓰기 전 승인" 원칙에 따라 **사용자 승인 없이
  `create_event`를 호출하지 않는다.**

## 입력

- 실행 기준일(오늘)과 대상 기간: **오늘 ~ 3개월 후**. 이 기간은 캘린더 중복 조회와
  신작 수집·등록에 **동일하게** 적용한다(당월 + 이후 2개월, 예: 7월 실행 시 7·8·9월).
- 필수 MCP:
  - Google Calendar MCP — `list_events`(중복 확인), `create_event`(등록).
  - Chrome MCP — `navigate`, `get_page_text`, `javascript_tool`
    (클라이언트 렌더링 사이트 접근용).
- 기본 리서치 소스:
  - 인벤 게임 캘린더 — https://www.inven.co.kr/webzine/calendar/ (실행일부터 3개월치: 당월~+2개월)
  - 인벤 사전예약 Pick — https://pick.inven.co.kr/
  - 루리웹 신작 목록 — https://bbs.ruliweb.com/news/ 에서 "월별 출시 목록" 검색
    (URL 패턴 https://bbs.ruliweb.com/news/read/XXXXXX)
  - WAME 캘린더 — https://www.wame.is/ko/calendar/list
  - 웹 검색 보완 — "[현재월] 신작 게임 site:inven.co.kr OR site:ruliweb.com",
    "한국 출시 [현재월] [현재년] 게임", 주요 게임사 공식 공지(넥슨, 엔씨,
    크래프톤, 넷마블 등).
- 입력이 비었을 때 기본 동작: 루리웹 월별 목록 미게시 시 인벤 + WAME + 웹 검색으로
  대체한다. Google Calendar 조회/등록 실패 시 중복 체크 없이 전체 결과를 채팅에만
  출력하고 실패 사실을 명시한다.

## 리서치 절차

1. **캘린더 기존 일정 조회** — `list_events`로 오늘~3개월 이벤트를 불러와 제목
   목록을 `calendar_titles`에 저장한다. 게임명 비교 시 대소문자·공백·특수문자
   차이는 무시하고 핵심 이름만 비교한다("리그 오브 레전드" == "League of Legends"는
   동일로 간주).
2. **소스 리서치** — 위 기본 리서치 소스를 순서대로 확인한다. 대상 기간(오늘~3개월)에
   드는 **모든 달**을 확인한다(예: 7월 실행 시 7·8·9월). 루리웹 월별 목록이 아직
   게시되지 않은 달은 인벤/WAME 캘린더(클라이언트 렌더링 → Chrome MCP)와 웹 검색으로
   보완하고, 확정 출시일이 없는 항목은 등록하지 않는다.
3. **수집 기준**
   - 출시일이 확정된 게임만 (날짜 미정 제외, 단 사전예약 섹션은 예외).
   - 플랫폼 필터(필수): PC(Steam/온라인)·모바일만. 콘솔 전용 제외.
     - 포함: PC(Steam, 온라인), 모바일(Android/iOS).
     - 제외: PS5/PlayStation 전용, Xbox 전용, Nintendo Switch 전용.
     - 멀티플랫폼(PC + PS5 등)은 PC 버전이 있으면 포함. 콘솔 전용 정보는 생략하되,
       PC 안의 유통 스토어(Steam / Epic / Microsoft Store / GOG / Game Pass 등)는
       반드시 표기한다.
   - 규모 필터(필수): 아래 중 하나에 해당하면 **등록 후보**, 아니면 **참고 목록**으로
     내린다. 참고 목록은 등록하지 않고 별도 섹션에만 표시한다.
     - 대형·중견 퍼블리셔 타이틀(예: 액티비전, Xbox Game Studios, 반다이남코, 캡콤,
       스퀘어에닉스, 2K, 코나미, EA, 유비소프트, Arc System Works, Focus, 505 Games,
       Epic Games Publishing 등)
     - 국내 게임사 신작(넥슨, 엔씨, 넷마블, 크래프톤, 카카오게임즈, 스마일게이트,
       데브시스터즈, 조이시티, 네오위즈, 그라비티 등) 또는 국내에서 화제가 된 국산 인디
     - 알려진 IP·시리즈 후속작·리메이크·리마스터
     - 대형 업데이트(시즌/대규모 콘텐츠 패치) — PC/모바일 대상에 한함
     참고 목록으로 내리는 예: 개인·소규모 팀 인디, 무료 소품, 얼리액세스 진입,
     퍼블리셔 없이 자체 출시하는 무명 타이틀.
     판단이 애매하면 등록 후보에 두고 보고서에 판단 근거를 한 줄 적는다.
   - 사전예약은 별도 섹션으로 분리.
   - 각 항목: 개발사/퍼블리셔, 장르, 플랫폼 확인. 플랫폼은 PC/모바일 구분에서
     그치지 말고 **유통 스토어까지 표기**한다. 예) `PC (Steam)`,
     `PC (Steam / Epic / Game Pass)`, `PC (Steam / Microsoft Store / Game Pass)`,
     `모바일 (Android / iOS)`. 자체 런처 배포면 런처명을 적는다(예: `PC (넥슨 런처)`).
     스토어가 확인되지 않으면 `PC (스토어 확인 필요)`로 남기고 임의로 Steam이라
     단정하지 않는다.
4. **중복 필터링** — 각 게임을 `calendar_titles`와 비교한다. 이미 있으면 등록
   제외("이미 등록된 게임"에 표시), 없으면 등록 후보로 둔다.

## 등록 절차 (승인 게이트)

`create_event` 호출 전 반드시 아래 순서를 따른다.

1. 등록 후보 목록을 채팅에 먼저 출력한다.
2. 사용자가 "등록해/추가해" 등 명시적으로 승인한 항목만 `create_event`로 등록한다.
   일부 제외 요청 시 나머지만 등록한다.
3. 자동 실행(스케줄)으로 사용자가 없으면 목록만 남기고 등록하지 않은 채 대기한다.

등록 형식:
- 제목: 일반 신작 `🎮 {게임명} 출시 (PC)` / `🎮 {게임명} 출시 (모바일)`,
  업데이트 `🔄 {게임명} 업데이트 (PC)`. **인디 신작은 제목에 `[인디]`를 붙인다**:
  `🎮 [인디] {게임명} 출시 (PC)`.
- 색상: 이벤트 colorId를 탠저린(`6`)으로 지정해 기존 게임 일정과 통일한다.
- 날짜: 출시/업데이트 확정일(하루짜리 일정).
- 설명: 장르, 플랫폼(유통 스토어까지, 예: `PC (Steam / Game Pass)`),
  개발사/퍼블리셔 포함.
- 사전예약은 캘린더 등록 대신 채팅에만 표시한다(출시일 미정이 많음).

## 출력

리서치 결과는 **한국어**로 아래 형식으로 출력한다. 보고서 맨 마지막에 등록 여부
질문을 둔다.

```markdown
# 🎮 한국 신작 게임 리서치 — YYYY년 M월 D일

## ✅ 등록 후보 (아직 등록 안 됨 — 승인 후 추가)

| 날짜 | 게임명 | 종류 | 개발사 | 퍼블리셔 | 장르 | 플랫폼 |
|------|--------|------|--------|----------|------|--------|

## ⏭️ 이미 등록된 게임 (건너뜀)
- 게임명A (M/D)

## 📎 참고 목록 — 규모 필터로 제외 (등록 안 함)

| 날짜 | 게임명 | 개발사/퍼블리셔 | 장르 | 플랫폼 |
|------|--------|----------------|------|--------|

## 🔔 사전예약 진행 중 (참고용)

| 게임명 | 플랫폼 | 개발사/퍼블리셔 | 예약 보상 | 출시 예정 |
|--------|--------|----------------|-----------|-----------|

## 📌 출처
- 인벤 캘린더, 루리웹, WAME 등 (검색일: YYYY-MM-DD)

> ⚠️ 아직 캘린더에 등록하지 않았습니다.
> 위 후보를 등록할까요? (등록해 / 건너뛰기)
> 참고 목록의 항목도 함께 등록하려면 그 항목만 지정해 주세요.
```

등록 후보가 없으면:

```markdown
# 🎮 한국 신작 게임 리서치 — YYYY년 M월 D일
> 새로 등록할 신작 게임이 없습니다. 이미 등록된 일정: N건
```

## 게이트

다음을 모두 통과해야 등록 단계로 넘어간다.

1. `list_events`로 기존 일정을 조회해 `calendar_titles`를 만들었다(또는 조회 실패를
   명시했다).
2. 수집한 게임이 플랫폼 필터(PC/모바일)와 출시일 확정 기준을 통과했다.
3. 중복 필터링으로 등록 후보와 이미 등록된 게임을 분리했다.
4. 등록 후보 목록을 채팅에 출력하고 등록 여부를 물었다.
5. 사용자의 명시적 승인이 있다(자동 실행은 승인으로 보지 않는다).

## 중단 조건

- 사용자 승인 전에 `create_event`로 등록하려는 경우 → 멈추고 승인을 먼저 받는다.
- 자동 실행(스케줄)이라 사용자가 없는 경우 → 등록하지 않고 후보 목록 + 등록 질문만
  남긴 채 대기한다.
- Google Calendar 조회 실패 → 중복 체크 없이 채팅 출력만 하고 실패를 명시한다
  (등록 강행 금지).
- 출시일 미확정 게임을 확정 출시로 등록하려는 경우 → 메인 테이블에서 제외하고
  사전예약 섹션으로만 둔다.
- 소스 정보가 충돌 → 공식 채널(개발사 공지) 기준으로 확인하기 전까지 확정 기재하지
  않는다.

## 다음 단계 전달물

- 파이프라인 다음 단계는 없다. 수요자는 사용자와 사용자의 구글 캘린더다.
- 전달물: (1) 채팅 리서치 보고서, (2) 승인 후 등록된 캘린더 이벤트(제목/날짜/설명).
- 상태 표기: 등록 전 = "등록 후보(미등록)", 승인·등록 후 = "등록 완료".

## AI가 확정하지 말 것

- 캘린더 등록 여부(항상 사용자 승인 필요).
- 출시일이 확정되지 않은 게임의 날짜.
- 소스 간 충돌 시 공식 확인이 없는 정보.
- 콘솔 전용 타이틀 포함 여부(기준상 제외이나 예외는 사용자 판단).

## 좋은 요청 예시

```text
이번 달하고 다음 달 한국 PC·모바일 신작 출시 정리해줘.
구글 캘린더에 이미 있는 건 빼고, 등록 후보만 표로 보여준 다음 등록할지 물어봐.
사전예약은 참고용으로 따로 정리해줘.
```

## 한계와 주의

- 날짜 미확정 게임은 메인 테이블에 넣지 않는다(사전예약 섹션 제외).
- 개발사/퍼블리셔 미상이면 추가 검색으로 확인한다.
- 루리웹 월별 목록 미게시 시 인벤 + WAME + 웹 검색으로 대체한다.
- 클라이언트 렌더링 사이트는 웹 페치로 안 되므로 Chrome MCP를 사용한다. 데이터가
  비면 몇 초 대기 후 재시도한다.
