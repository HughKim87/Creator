# 후보 선별과 음원·자막 검수

## 후보로 남길 기준

| 유형 | 독립적으로 볼 만한 내용 | 제거/보완 신호 |
|---|---|---|
| 게임/현장 | 실제 사건과 반응 또는 결과 | 비명만 남음, 사건 화면 누락, 목적 없는 이동 |
| 리뷰 | 짧은 주장과 경험/근거·결론 | 조건을 잘라 과장, 제품/주어가 불명확 |
| 설명 | 질문/오해와 답·유용한 예시 | 용어만 나열, 답이 다음 장면인데 빠짐 |
| 대화 | 질문과 답, 공감/재치·의견 완결 | 상대 말 삭제로 의미 변화, 발화자 불명확 |

한 고정 점수로 모든 영상을 분류하지 않는다. 이유는 실제 내용을 한 문장으로 적고 조회수를 예측한 사실처럼 쓰지 않는다. 대체 구성이 유의미할 때만 같은 사건을 별개로 제시한다. 의미 있는 사건을 임의의 길이에 맞춰 끊지 않는다. 플랫폼 최신 규격이 필요하면 별도로 확인한다.

특정 챕터를 더 찾으라는 피드백은 그 범위에 적용하고 기존 선택/번호를 보존한다.

## 탐색 자막과 출력 자막

단어가 맞아도 시간이 틀릴 수 있다. 자막 시간 문제와 단어 문제를 별개로 판단한다. 검증 전에는 동기화 자막을 숨기고 제공 자막 내용을 검색 근거로만 쓴다.

후보 전후 문맥을 포함해 원음을 분석한다. word times를 실제 parts 안으로 제한하고, 각 part 시작을 뺀 후 앞 parts 길이 합을 더해 합성 좌표로 매핑한다. 삭제한 발화/자막은 새 영상에 남기지 않는다.

ASR은 설치된 엔진/모델을 사용한다. 시간/신뢰도/문맥과 원음 확인을 함께 사용하며 낮은 신뢰도만으로 자동 삭제하지 않는다. 필요한 비교 전사를 무힌트로 한 번 수행할 수 있지만 모든 파일을 무조건 반복 전사하지 않는다.

## 이번 작업에서 확인된 실패와 좁은 예방책

- 힌트 또는 미검증 quantization 결과에 무관한 문구가 반복 혼입되면 그 결과를 폐기하고 무힌트·지원되는 정밀도로 후보 구간을 재시도한다. 모든 ASR의 quantization을 금지하는 것은 아니다.
- 긴 CPU 추론은 후보만 처리하고 긴 구간은 발화 경계나 제한된 겹침으로 나눈다. 겹친 단어는 원본 timestamp로 제거하되 실제 반복한 발화를 삭제하지 않는다.
- 비명/숨/웃음은 단어로 잘못 인식될 수 있다. 비언어 장면에 유창한 대사를 invent하지 않는다. 필요한 경우 `[비명]`, `[웃음]`과 발화를 구분한다.
- 문맥상 이상한 표현이 같은 모델에서 두 번 나와도 확정되지 않는다. 원문·시점·가능한 표현을 사용자에게 보여주고 확인받는다. **최종 전 확인**을 에이전트의 임의 자막 생략으로 대체하지 않는다.
- scale/pad 이후 `setsar=1`을 명시하고 ffprobe의 DAR/SAR와 브라우저 표시 크기를 확인한다.

불확실 항목에 stable issue id/clip 시각/현재 표현/가능한 표현/이유를 기록한다. 컷이 바뀌면 issue와 revision을 갱신한다. 사용자의 교정/생략 선택을 근거로 남긴다. 무응답은 승인이 아니다.

구조 검증, 자동 전사 대조, 실제 청취, 사용자 확인은 다른 근거다. 청취 도구가 없으면 `actual_listening: not_run`; 실제 청취 또는 사용자 확인이 있으면 그 관측 범위만 기록한다.
