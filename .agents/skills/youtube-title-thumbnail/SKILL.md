# YouTube Title and Thumbnail

완성 영상에서 실제로 다루는 약속을 제목과 썸네일로 압축한다. 사실을 새로 만들거나 채널 스타일을 추정하지 않는다.

## 입력

다음을 확정한다.

- 정확한 완성 영상
- 검증된 SRT 또는 원본 대본
- 사용한 리서치 자료나 핵심 근거
- 선택적 채널 URL·최근 영상 패턴
- 산출물을 둘 Git 제외 런타임 폴더

영상과 SRT가 서로 맞는지 길이·주제·파일명을 확인한다. 제목과 썸네일에 쓰는 모든 수치·제품명·비교 주장은 대본이나 리서치에서 추적 가능해야 한다.

## 채널 근거 확인

채널 정보가 있으면 최근 영상에서 다음만 읽기 전용으로 확인한다.

- 제목의 길이와 검색 키워드 위치
- 썸네일의 문구 수, 색상, 인물 사용 여부
- 정보형·비교형·리뷰형 중 주된 포맷

지원되는 브라우저 연결이 실패하면 제공된 복구 절차까지만 수행한다. 같은 목적이 반복 실패하면 다른 비공식 제어 방식으로 우회하지 말고 `channel_evidence.status`를 `unavailable`로 기록한다. 채널 스타일을 임의로 재현하지 않고 영상 근거만으로 계속 진행한다.

## 제목 설계

1. 대본에서 대상 시청자, 핵심 변화, 실무 이득, 주의점을 추출한다.
2. 비교형·사용법형·가성비형·경고형·총정리형을 포함해 후보 5개를 만든다.
3. 핵심 검색어를 앞 4~5단어 안에 둔다.
4. 제목은 기본적으로 40~65자로 만들고, 영상에서 다루지 않는 최상급·확정 표현·공포 유도는 제외한다.
5. 썸네일 문구와 제목이 같은 문장을 반복하지 않게 한다.
6. 명확성, 검색 의도, 영상 충실도, 호기심, 채널 적합성을 비교해 하나를 `draft`로 선정한다.

사용자가 명시적으로 승인하기 전에는 `user_approved: false`로 둔다.

## 썸네일 설계

대표 프레임 3~5장을 시작부·핵심 비교·결론 구간에서 고른다. 새 배경이 필요하면 `references/thumbnail-brief-template.md`를 읽고 이미지 생성 스킬을 사용한다.

- 생성 모델에는 글자 없는 배경만 요청한다.
- 정확한 한글·제품명·숫자는 로컬에서 합성한다.
- 핵심 문구는 2~3개 블록으로 줄이고 모바일 크기에서도 읽히게 한다.
- 제목을 그대로 반복하는 대신 시청자의 선택·손실·결과를 보완한다.
- 16:9, 최소 1280×720, 안전 여백, 강한 명암 대비를 유지한다.
- 원본 PNG와 업로드용 JPG 또는 PNG를 함께 보존한다.

글자 합성에는 `scripts/render_thumbnail.py`를 사용한다.

```powershell
python scripts/render_thumbnail.py <background.png> `
  --output-png <thumbnail.png> `
  --output-jpg <thumbnail.jpg> `
  --preview <thumbnail-preview-320.jpg> `
  --line-1 "GPT-5.6" `
  --line-2 "뭘 써야" `
  --line-3 "이득일까?" `
  --badge "3모델 × 6단계"
```

Pillow가 없으면 사용자 승인 없이 설치하지 않는다. 한글 폰트를 자동으로 찾지 못하면 `--font <font.ttf>`를 지정한다. 생성·렌더링 같은 장시간 작업의 상태는 **5분 간격으로만** 확인한다.

## 패키지 기록

`references/package-format.md`에 따라 런타임 JSON을 만든다. 후보 전체, 선택 제목, 썸네일 문구, 배경 생성 프롬프트, 입력과 출력 경로, 채널 근거 상태, 시각 검토 여부, 사용자 승인 여부를 보존한다.

`scripts/validate_package.py <package.json>`으로 다음을 확인한다.

- UTF-8, NUL, 필수 필드와 스키마 버전
- 선택 제목이 후보에 포함되고 40~65자인지
- 영상·SRT·썸네일 경로가 실제로 존재하는지
- 썸네일이 16:9이고 최소 1280×720인지
- 업로드 이미지 형식·크기·SHA-256
- 모바일 축소 시각 검토와 사용자 승인 상태

자동 검증은 문구 가독성이나 채널 적합성의 사용자 승인을 대신하지 않는다. 320×180 미리보기를 직접 확인하고 오탈자·잘림·과도한 복잡도를 검토한다.

## 반환 결과

- 제목 후보 5개와 선정 이유
- 최종 제목 초안과 글자 수
- 썸네일 배경, PNG 원본, 업로드 파일, 모바일 미리보기 경로
- 배경 생성 프롬프트와 정확한 합성 문구
- 패키지 JSON과 검증 결과
- 사용한 채널 근거 또는 확인 불가 상태
- 사용자 승인 여부

## 정지 조건

제목·썸네일·패키지를 검증한 뒤 멈춘다. 후속 스킬은 수동 업로드 자료만 준비하며, 실제 YouTube 업로드·게시·공개 범위 설정은 사용자가 직접 수행한다.
