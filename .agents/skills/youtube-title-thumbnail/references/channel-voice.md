# 채널 말투 적용

- 목적: 제목·제작 브리프·댓글의 표현과 사실 주장 범위를 일관되게 맞춘다.
- 읽는 시점: 사용자가 채널 말투 반영을 요청하거나 기존 스타일 자료를 제공했을 때.
- 책임: 각 스킬은 현재 승인된 스타일만 적용하고 사용자는 채널의 표현 선호를 결정한다.
- 상태: 선택적 공통 참고. 프로필 생성이나 영상 제공은 작업의 필수 전제가 아니다.
- 관련 권위: 현재 사용자 요청, 각 작업의 자료 접근 범위와 기존 스킬의 검수·게시 경계.

기존 대화·명시된 프로필에서 다음을 재사용한다. 없으면 짧은 기본 존댓말로 진행하고 추정임을 밝힌다. 필요한 경우에만 말투 예시나 미정 선호를 묻는다. 영상 세 편 제출을 의무화하지 않는다.

| 항목 | 적용할 내용 |
|---|---|
| 시청자 | 현재 채널이 답하려는 질문과 배경지식 |
| 표현 | 존댓말/반말, 문장 호흡, 자주 쓰는 표현, 이모지 사용 |
| 피할 표현 | 과장, 원하지 않는 유행어·비하·인위적인 친근함 |
| 주장 범위 | 직접 해본 것·출처에서 확인한 것·추정·미확인을 구분하는 표현 |
| 형식 | 설명·리뷰·실황에 맞는 도입과 마무리 |

사용자가 지속 프로필 저장을 요청하면 프로젝트 내부에서 지정한 비보호 스타일 owner에 정리하고 각 스킬이 같은 자료를 참조한다. 개별 댓글·영상 원문·계정 정보는 공통 스킬에 복제하지 않는다. 영상별 선택·임시 추정은 해당 job 근거에 두며 채널 전체 선호로 승격하지 않는다. 단독 요청은 채팅 결과만으로 충분하다.

말투 적용 뒤 숫자·경험·출처가 새로 생기지 않았는지 검토한다. 글꼴·줄바꿈에 따른 가독성, 실제 음성과 자막은 각 기존 검수가 담당한다. 참고 아이디어: [voice.md](https://github.com/Jakeschincariol/youtube-agent-skill/blob/main/templates/voice.md). 이 문서는 한국어 작업용으로 새로 작성한 지침이다.
