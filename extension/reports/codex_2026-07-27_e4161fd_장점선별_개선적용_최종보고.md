## 4. 기능별 검증 결과

### Claude 시작 경로

- `@AGENTS.md` 참조 1개
- policy owner는 `PROJECT_RULES.md`, 현재 상태 owner는 `SESSION_HANDOFF.md`
- 과거의 잘못된 handoff 크기 전제 제거
- 보호 경로와 `.agents/skills/` route만 Claude 도구 차이로 유지

### SRT

- UTF-8·BOM·CRLF 처리
- index·timestamp·양수 길이·순서·겹침·미디어 종료 검증
- cue별 `start_ms`·`end_ms`와 명시 제외만 허용
- 본문과 원본 SHA-256 불변
- destination 부모 자동 생성 금지, 기본 비덮어쓰기
- 실패 시 destination·temporary file 0

### legacy CSV와 다중 진단

- 필수 열은 `idx,track,name,src_in,src_out,frames,tl_start,tl_end,gap_before`
- frame·timeline·gap·행 순서 보존
- 누락 열·정수·중복 idx·track·범위·연속성·A/V 오류를 결정적 순서로 보고
- issue 필드는 `code / message / track / clip_id / index`
- importer는 `edit_role: unclassified`, `semantic_gate: pending`만 생성
- 의미 검수 전 XML 생성 차단

### Premiere XML profile

- 기본 `sequence-v5`는 11,629 byte, SHA-256 `9553f10ace7728334187edaafe159d2a4a02b8afdcb21ad95ad65d0a226de100` 유지
- `premiere-cs6-v4`는 declaration·DOCTYPE·xmeml v4·project·bin·masterclip·sequence 생성
- source file 정의 1개와 동일 `file-1` reference 사용
- video/audio 범위·audio gap·channel별 sourcetrack·output channel·link 보존
- UUID는 canonical timeline에서 결정적으로 생성
- frame rate·해상도·sample rate·channel은 source metadata 사용
- 반환 상태는 `structure-validated`
