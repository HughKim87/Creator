# 백룸 full-edit-v18 기술·의미 진단

- 목적: 마지막 참고 XML인 `full-edit-v18`의 재사용 가능 범위와 실제 A/V 검증 대상을 결정한다.
- 읽는 시점: 백룸 대표 구간 재편집 또는 전체 편집 기준본을 선택하기 전.
- 책임: 작업 에이전트가 구조·의미·실제 재생 검증을 분리하고, 사용자 승인 전에는 후보를 기준본으로 승격하지 않는다.
- 상태: XML·SRT 기반 구조 및 의미 진단 완료. v18은 source map으로만 사용하며, calibration-v3-r1은 사용자 요구 불일치로 폐기됐다. 후속 단일 sequence 후보는 별도 보고서가 소유한다.
- 관련 권위: `core/PROJECT_RULES.md`, `PROJECT_RULES.md`, `extension/reports/2026-08-26_BACKROOM_EDITING_RESUME_PLAN.md`.

## 1. 판정

`2026-06-30 00-23-03.full-edit-v18.xml`은 r2 이후에 만들어진 전체 편집본이며 XML에서 측정한 길이는 14분 15.85초다. 이 값은 과거 artifact의 기술적 측정치일 뿐 목표 시간·상한·합격 기준이 아니다. 시간 순서와 이야기 뼈대는 회수 가치가 있지만, 검증·승인 lineage가 없고 발화 단절 위험 경계가 많아 `current`, `approved`, 재편집 기준본으로 바로 사용할 수 없다.

가장 안전한 사용법은 다음과 같다.

- v18: 전체 이야기 순서와 장면 선택을 회수하는 source map
- `integrated-calibration-v2-r2`: A/B/C 대표 구간의 안전한 연속 source 범위
- 새 revision: v18의 이야기 뼈대에 r2의 경계 원칙과 2차 편집을 적용한 검증 후보

v18 XML은 수정하거나 덮어쓰지 않는다.

## 2. 확인한 입력

| 입력 | 확인 결과 | 역할 |
|---|---|---|
| `inputs/2026-06-30 00-23-03.mp4` | 3,799,793,770 bytes | 원본 영상 |
| `inputs/2026-06-30 00-23-03.srt` | 731 cues, NUL 0 | 발화·경계 근거 |
| `inputs/2026-06-30 00-23-03.full-edit-v18.xml` | XMEML 정상 파싱 | 참고 전체 편집 |

MP4 크기는 기존 handoff 기록과 정확히 일치한다. XML의 source duration `295444 frames / 60fps = 4924.0667초`도 기존 기록과 일치한다. 전체 파일 hash와 실제 디코드는 아직 확인하지 않았다.

SRT 마지막 cue는 `01:22:04.090–01:22:05.940`으로 XML source duration보다 약 1.873초 뒤까지 이어진다. 현재 편집의 마지막 source out은 `4917.900초`보다 앞이므로 즉시 충돌하지 않지만, 최종 자막 생성 전 source 끝 경계를 다시 확인해야 한다.

## 4. 발화 경계 위험

165개 영상 경계 가운데 source가 그대로 이어지는 경계는 11개이고, source 점프가 있는 경계는 154개다.

SRT cue와 대조한 source 점프 경계 분류는 다음과 같다.

| 분류 | 수 | 의미 |
|---|---:|---|
| 같은 cue 내부를 건너뜀 | 43 | 한 발화 안의 일부를 생략했을 가능성 |

## 5. v18과 r2 대표 구간 관계

### A — 첫 진입

- r2: `322.421–343.438`, 21.017초 연속 구간
- v18: `324.917–364.400`, 39.483초 한 컷

v18은 r2 시작보다 2.496초 늦게 들어가고, r2 끝보다 20.962초 더 이어진다. `영화에서 보던 장면`이라는 소재는 유지하지만 첫 진입의 시작 과정 일부를 버리고 훅을 약 39.5초까지 늘렸다.

**판정:** 이야기 소재는 재사용한다. 39.5초 길이와 처음 2.496초 제외가 실제로 훅을 강화하는지는 A/V 전에는 확정하지 않는다. r2와 v18 두 경계를 직접 비교해야 한다.

### B — 규칙·허세·공포 붕괴

- r2: `2333.217–2351.207`, 17.990초 연속 구간
- v18: `2326.950–2355.700`, 28.750초 한 컷

v18은 r2 전체를 포함하고 앞뒤 문맥을 더 보존한다. `마주쳤어 → 도발 → NPC 수준이라는 허세 → 무섭다는 인정 → 도주 → 규칙 이해`가 한 사건 안에 있다.

**판정:** v18에서 가장 강한 재사용 후보다. 다만 약 10.76초 늘어난 문맥이 감정 피크를 강화하는지 늦추는지는 실제 재생으로 비교한다.

### C — 적응 뒤 남은 공포

- r2: `4342.274–4354.669`, 12.395초 연속 구간
- v18:
  - `4342.033–4348.183`
  - `4348.533–4351.483`
  - `4351.833–4354.683`

v18은 r2와 거의 같은 발화를 쓰지만 두 곳에서 각각 0.350초를 생략해 세 조각으로 나눴다. 내용은 `반복할수록 익숙해짐 → 처음 상황에서는 → 여전히 공포가 남음`으로 중심 메시지와 정확히 일치한다.

**판정:** 메시지는 재사용하되, 경계는 r2 연속 구간을 우선한다. 0.350초 두 번의 생략이 호흡을 개선한다는 실제 A/V 근거가 있을 때만 v18 분할을 채택한다.

## 6. 이야기와 편집 방향 진단

### 회수할 강점

- source 시간 역행 없이 처음부터 방송 종료까지 순차적으로 진행한다.
- 첫 진입, 공간 공포, 첫 사망, 규칙 학습, 허세와 붕괴, 적응, 남은 긴장으로 캐릭터 변화가 존재한다.
- 백룸의 환경음, 빈 공간, 방향감각, 빛, 문, 계단, 열쇠, 아몬드 물 같은 공간·규칙 소재를 실제 행동에 연결한다.
- B의 허세 붕괴와 C의 적응·공포 잔존은 현재 작업계획의 중심 방향과 일치한다.
- v18 clip 이름은 source 장면 지도와 이야기 선택 근거로 재사용할 가치가 높다.

### 그대로 유지하면 위험한 부분

- 첫 컷 39.483초와 13개의 10초 초과 컷은 사건 근거가 있어도 시청 호흡이 느릴 수 있다.
- A10–A12는 약 265.77초로 전체의 약 31%를 차지한다. 주차장 추격·안전실·규칙 설명이 중심부를 과도하게 점유할 가능성이 있다.
- `적응했다`, `안 무섭다`, 다시 무너진다는 변화가 A06·A08·A10·A13·A17·A19에서 반복된다. 단계적 성장으로 읽히지 않으면 같은 메시지를 여러 번 설명하는 구조가 된다.
- 많은 source 점프가 긴 SRT cue 내부에 있어 말의 자연스러운 절보다 화면 압축을 우선했을 가능성이 있다.
- 전환·효과가 없다는 사실 자체는 결함이 아니지만, 모든 리듬을 하드컷과 원본 음성만으로 해결해야 하므로 경계 품질 의존도가 매우 높다.
- A20–A21 결말은 긴 source 간격을 건너 `남은 긴장 → 규칙 회고 → 방송 종료 농담`을 연결한다. 의미 회수인지 설명식 정리인지 실제 A/V로 판정해야 한다.
