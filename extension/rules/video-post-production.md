# 영상 후편집 규칙

- 목적: 컷 편집이 끝난 영상에 자막·효과·카드·이미지·오디오를 더할 때 원본 사실을 지키면서 시청 경험을 강화한다.
- 읽는 시점: 컷 timeline 이후의 자막·효과음·화면 효과·정보 카드·외부 이미지·음악·음량을 설계하거나 적용·수정할 때.
- 책임: 영상 편집 작업 에이전트가 후편집 설계·근거·검수를 유지하고 사용자가 연출 방향과 결과를 승인한다.
- 상태: 활성 소비 도메인 규칙.
- 관련 권위: `extension/docs/domain/youtube/VIDEO_EDITING_WORKFLOW_CONTRACT.md`가 범위와 완료 gate를, `extension/docs/domain/youtube/VIDEO_EDITING_PROFILES.md`가 채널·장르 기본값을 소유한다.

### R19 — 원본 기반 연출과 정보

- 조건: 강조 자막·효과음·화면 효과·정보 카드·밈 같은 외부 이미지를 추가한다.
- 행동: 강조 자막·효과음·확대 같은 강조 연출은 원본의 실제 반응·사건 직후에 붙이고, 원본에 없는 사건·감정·위협을 만들지 않는다. 화면에 넣는 설명·정보 문구는 원본 화면이나 공식 자료처럼 출처가 확인된 사실만 쓰고, 확인하지 못한 이름·수치는 비우거나 확인된 범위만 표시한다. 정보 카드는 긴장·몰입 구간을 끊지 않도록 화자의 설명이나 쉬는 지점에 맞춘다. 밈 같은 외부 이미지는 사용자가 지정한 출처에서만 고르고 자체 제작 대체물을 만들지 않으며, 영상의 핵심 내용을 가리지 않는 크기·위치에 둔다.
- 예외: 패러디처럼 연출임이 명백한 장치는 원본 사실을 오인시키지 않을 때만 쓴다. 사용자가 특정 위치·장면에 이미지를 요청하면 그 요청을 따르되 핵심 내용 가림 여부를 확인한다.
- 검증: 강조 연출마다 대응하는 원본 반응 위치가, 정보 문구마다 출처가, 외부 이미지마다 출처 경로가 기록돼 있고, 긴장 구간에 들어간 정보 카드에는 이유가 있는지 확인한다.

- 행동 보강: 외부 이미지마다 앵커 발화의 실제 끝 시각, 삽입 순간과 직후 화면, 앞뒤 맥락, 이미지의 글자·표정이 가리키는 대상을 확인한다. 이미지의 대상과 발화 대상이 일치할 때 사용하고, 다음 장면까지 이어질 기능이 없으면 장면 전환 전에 끝낸다.
- 검증 보강: 외부 이미지별 앵커 발화·화면·맥락 판단과 종료 위치가 작업 근거에 기록됐는지 확인한다.

### R20 — 후편집 설계·샘플·부분 수정

- 조건: 후편집을 시작하거나 레이어를 추가·수정한다.
- 행동: 타겟 시청자와 시청 맥락(주 시청 기기 포함)을 먼저 정리하고, 자막·카드·강조·이미지·오디오·패키징 레이어별 기능과 사용 조건을 정한 뒤 컷 timeline 기준 큐시트를 만든다. 편집 프로필의 기본값을 상속하고 바꾼 값은 이유를 적는다. 샘플은 고정 길이가 아니라 판단에 필요한 레이어 종류가 모두 들어가는 가장 작은 연속 구간으로 만들고, 사용자 확인 뒤 전체로 확장한다. 사용자 지적은 지적된 한 곳이 아니라 같은 종류 전체에 적용할 기준으로 기록해 이후 판에 상속한다. 수정은 바뀐 구간만 다시 만들고 나머지 구간이 이전 판과 같은지 확인하며, 새 판은 새 이름으로 만든다. 후편집 중 컷 내용을 바꿔야 하면 컷 편집 revision으로 돌아가 해당 규칙을 다시 적용한다.
- 예외: 사용자가 레이어 범위를 확정했거나 연출 결정을 위임했으면 확인 질문만 생략하고 설계와 샘플 단계는 유지한다.
- 검증: 큐시트 항목마다 레이어·기능·timeline 위치가 있고, 전체 확장 전에 샘플 확인 결과가 있으며, 사용자 지적이 기준으로 기록돼 이후 판 전체에 적용됐는지, 부분 재생성에서 바뀌지 않은 구간이 이전 판과 같은지, 후편집 결과의 컷 내용이 기준 컷 timeline과 같은지 확인한다.

### R21 — 자막 정확도와 가독성

- 조건: 전체 자막이나 화면 글자 레이어를 만들거나 시간을 보정한다.
- 행동: 자막은 검증된 전사와 실제 발화 시각으로 만들고, 불명확한 단어·고유명사·속어·비명은 원본 청취와 화면 맥락으로 교차확인하기 전까지 확정하지 않으며, 확인하지 못한 대사는 불확실 목록에 남기고 필요하면 표시를 생략한다. 자동 시간 보정은 독립 인식이나 청취로 보정 전후를 비교해 나아진 항목만 채택한다. 글자 크기와 줄 수는 주 시청 기기에서 읽히는 기준으로 정하고, 실제 렌더 폭에 맞춰 줄바꿈하며 넘치는 문장은 시간으로 나눈다. 자막·카드·강조 글자·이미지가 서로 겹치거나 원본 화면의 글자·UI를 가리지 않게 배치하고, 강조 글자는 일반 자막과 크기·서체로 구분한다.
- 예외: 번역 대체처럼 의도적으로 원본 글자를 덮는 연출은 위치와 목적을 기록한다.
- 검증: 자막 cue와 실제 발화 시각의 차이, 불확실 목록, 줄 수·폭 초과 0건, 레이어 사이와 원본 글자와의 겹침 0건을 확인한다. 자동 보정은 나빠진 항목이 0건인지 확인한다.

- 행동 보강: 컷 적용 뒤 편집본 오디오의 전사로 남은 말과 시각을 정하고, 원본 교정 자막은 표기를 대조하는 데 쓴다. 원본 cue의 단어를 컷 경계에서 임의 분배하지 않는다. 전사와 교정 표기가 다르면 독립 인식·청취·문맥의 판정 근거를 남기며, 같은 모델·설정의 재전사만으로 한쪽을 확정하지 않는다. 같은 발화를 일반 자막과 강조 글자로 동시에 표시하지 않고, 강조할 때는 그 시간의 일반 자막을 대체한다. 일반·보충 자막의 스타일은 편집 프로필을 따르며 의도된 차이는 설계에 기록한다.
- 예외 보강: 승인된 편집 프로필이 일반 자막·외부 이미지의 HUD 가림을 허용하면 해당 범위의 겹침은 허용한다. 핵심 사건·필수 정보·발화 이해를 가리는 배치는 허용하지 않으며, 정보 카드·강조 글자는 읽어야 할 원본 글자를 가리지 않는다.
- 검증 보강: 같은 발화의 중복 레이어, 프로필에서 설명되지 않은 스타일 차이, 판정 근거가 없는 전사·표기 충돌이 각각 0건인지 확인한다. 허용된 HUD 겹침과 그 밖의 가림을 구분해 기록한다.

### R22 — 합성·오디오 마감

- 조건: 레이어를 합성해 최종 영상을 만들거나 음량·음악·효과음 믹스를 마감한다.
- 행동: 음량은 배포 플랫폼 권장 통합 음량과 피크 상한에 맞추고 대사 명료도를 우선하며, 목표 수치는 편집 프로필에 둔다. 음악·효과음이 대사를 가리지 않게 한다. 레이어 합성 과정의 색·형식 변환이 원본 화면을 바꾸지 않도록 레이어가 없는 구간을 합성 전 원본과 비교한다. 최종 영상의 길이·프레임 수가 기준 컷 timeline과 같은지 확인한다. 승인된 아웃트로 등 추가 구간이 있으면 본편과 추가 구간의 frame/sample 수·순서·예상 총 길이를 조립 계획에 명시하고, 결합 후 전체 timestamp·프레임 수·길이와 음량·true peak를 다시 측정한다. 본편의 검사 결과를 결합본의 통과로 상속하지 않는다.
- 예외: 의도적으로 대사를 덮거나 화면을 변형하는 연출은 위치와 목적을 기록한다.
- 검증: 최종 파일의 통합 음량·피크 측정값이 프로필 목표 범위 안이고, 레이어 없는 구간의 화면이 원본과 같으며, 길이·프레임 수가 기준 컷 또는 승인된 조립 계획과 같은지 확인한다. 추가 구간이 있으면 경계의 음성·자막 시각과 전체 디코딩도 확인한다.

| ID | 상황 | 기대 판정 |
|---|---|---|
| TC27 | 원본에 반응이 없는 장면에 놀람 효과음을 넣으려 함 | 원본에 없는 감정을 만들지 않고 실제 반응 직후에만 강조한다 |
| TC28 | 레이어 설계 없이 전체 영상에 자막·효과를 한 번에 넣으려 함 | 큐시트와 짧은 연속 샘플 확인 뒤 전체로 확장한다 |
| TC29 | 자동 전사가 고유명사를 다르게 적음 | 원본 청취와 화면 맥락으로 확인하기 전까지 확정 자막으로 쓰지 않는다 |
| TC30 | 자막이 휴대폰 화면에서 너무 작다는 지적을 받음 | 주 시청 기기 기준으로 크기를 다시 정하고 이후 전체 확장에 같은 기준을 적용한다 |
| TC31 | 정보 카드가 큰 자막이나 원본 화면 글자와 겹침 | 겹치지 않는 위치로 옮기고 겹침 검사를 다시 실행한다 |
| TC32 | 투명 이미지 합성 뒤 레이어 없는 구간의 색이 미세하게 바뀜 | 합성 형식을 고정해 레이어 없는 구간을 원본과 같게 만든다 |
| TC33 | 화면에서 이름을 확인하지 못한 장소를 카드에 넣으려 함 | 확인된 번호·사실만 표시하고 이름은 비운다 |
| TC45 | 원본 교정 자막의 단어를 컷 클립에 나눠 자막을 만들려 함 | 컷 적용 뒤 오디오 전사로 남은 말과 시각을 정하고 교정본은 표기를 대조한다 |
| TC46 | 강조 글자를 같은 발화의 자막 위에 따로 얹으려 함 | 강조 글자는 그 시간의 일반 자막을 대신하고 같은 발화를 두 번 표시하지 않는다 |
| TC39 | 이미지의 글자·표정이 발화와 다른 대상을 가리킴 | 대상이 일치할 때만 쓰고 앵커 발화·화면·맥락 판단을 기록한다 |
| TC44 | 본편 음량은 통과했으나 아웃트로 결합본의 true peak가 목표를 초과함 | 결합본을 다시 마감·측정하고 최종 파일 통과 전에는 본편 pass를 상속하지 않는다 |
