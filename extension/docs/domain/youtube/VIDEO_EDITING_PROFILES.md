# 영상 편집 프로필

- 목적: 채널·장르별 편집 기본값을 규칙과 분리해 보관하고 영상마다 상속한다.
- 읽는 시점: 새 영상의 편집이나 후편집을 시작해 기본값을 정할 때.
- 책임: 영상 편집 작업 에이전트가 선택한 프로필과 바꾼 값을 작업 기록에 남기고, 사용자가 프로필 값을 확정한다.
- 상태: 참고 기본값. 규칙(R01~R22)을 대체하지 않으며, 규칙이 "편집 프로필"에 위임한 값만 정한다.
- 관련 권위: `VIDEO_EDITING_WORKFLOW_CONTRACT.md`, `extension/rules/`.

## 사용 방법

1. 편집 시작 시 가장 가까운 프로필을 고르고 작업 기록에 프로필 이름을 남긴다.
2. 영상에 맞게 바꾼 값은 이유와 함께 작업 기록에만 남긴다.
3. 같은 변경이 독립 영상에서 반복되고 사용자가 확정하면 프로필 값을 갱신한다.

## 프로필 항목

| 항목 | 의미 |
|---|---|
| 무발화 구간 기본값 | R09 기본 제거를 따르는지, 정적 분위기 자체가 목적인지 |
| 음악 정책 | 배경음악을 쓰는 구간과 쓰지 않는 구간 |
| 강조 연출 강도 | 강조 자막·효과음·확대를 붙이는 반응의 종류와 빈도 |
| 질감 효과 | 노이즈·필터 같은 화면 질감을 쓰는 위치 |
| 음량 목표 | 배포 플랫폼 기준 통합 음량 목표 |
| 주 시청 기기 | 글자 크기·배치 판단의 기준 화면 |
| 자막 | 전체 자막 여부, 글자 크기, 최대 줄 수, 외곽선 |
| 강조 글자 | 일반 자막과 구분되는 크기·서체 |
| 외부 이미지 | 허용 출처, 최대 크기, 배치 위치 |

## 게임 방송 프로필

- 상태: 초기값. 첫 적용 영상의 후편집 결과로 검증 중.
- 무발화 구간: R09 기본 제거. 탐색 결과·위협 등장·긴장 직전 정적처럼 화면 기능이 있는 구간만 유지.
- 음악: 긴장·공포 구간에는 배경음악을 쓰지 않고 게임 원음을 유지.
- 강조 연출: 실제 놀람·반응 직후에만 짧게.
- 질감 효과: 장·레벨 안내 같은 정보 카드에만 사용하고 본편 화면에는 쓰지 않음.
- 주 시청 기기: 휴대폰.
- 음량: YouTube 권장 통합 음량(-14 LUFS 부근), 피크 -1 dBTP 이하, 대사 우선.
- 자막: 전체 발화 자막 + 정보 카드. 전사 검증 후 확정. 1080p 기준 휴대폰에서 읽을 수 있는 큰 글자·굵은 외곽선·최대 2줄, 긴 문장은 시간 분할.
- 강조 글자: 일반 자막보다 크고 다른 굵은 서체.
- 정보 카드: 큰 자막과 겹치지 않는 화면 위쪽 모서리.
- 외부 이미지(밈): 사용자 밈 폴더에서만 선택, 자체 제작 그래픽 금지. 이미지마다 크기 조절, 최대 화면 가로·세로 절반, 영상 내용을 가리지 않게 좌·우 세로 중앙 배치. 자막은 그대로 둔다.

## 도깨비에서 확인한 게임 방송 프로필 변형

출처: `before-claude-dokkaebi`, `extension/docs/domain/youtube/VIDEO_EDITING_PROFILES.md`. 아래 값은 해당 작업에서 확정한 선택지이며 새 영상에 일괄 강제하지 않는다. HUD 가림 등 기존 프로필과 다른 값은 작업에서 이 변형을 명시적으로 선택한 경우에만 적용한다.


- 상태: 도깨비 1건 확인(2026-10-11 사용자 확정). 자막 스타일은 제우스와 2건 확인. 나머지 값은 독립 영상에서 다시 확인되면 상태를 올린다.
- 무발화 구간: R09 기본 제거. 탐색 결과·위협 등장·긴장 직전 정적처럼 화면 기능이 있는 구간만 유지.
- 음악: 긴장·공포 구간에는 배경음악을 쓰지 않고 게임 원음을 유지.
- 강조 연출: 실제 놀람·반응 직후에만 짧게. 영상당 10곳 안팎(도깨비 11곳).
- 연출 움직임: 등장 1회만(약 0.15초 페이드 + 살짝 확대, 또는 옆에서 밀려 들어옴) + 짧은 페이드아웃. 떨림·반복·과한 튕김 없음. 자막은 움직이지 않는다. CS6 XML에서는 프레임별 투명 PNG로 굽는다(PREMIERE_CS6_XML_COMPAT.md).
- 질감 효과: 장·레벨 안내 같은 정보 카드에만 사용하고 본편 화면에는 쓰지 않음.
- 주 시청 기기: 휴대폰.
- 음량: YouTube 권장 통합 음량(-14 LUFS 부근), 피크 -1 dBTP 이하, 대사 우선.
- 자막: 전체 발화 자막 + 정보 카드. 전사 검증 후 확정. 맑은 고딕 Bold 100px(1080p), 흰 글씨+검은 외곽선, 글자 경계에 맞춘 검은 상자(가로 30px·세로 15px 여백). **한 줄**, 넘치면 시간 분할(이전 '최대 2줄'은 사용자 선택으로 한 줄로 변경). 원본에서 다른 순간으로 넘어가는 컷에서 줄을 나눈다. 일반·보충 자막 모두 같은 스타일(색 강조 금지). 게임 HUD(스킬바·채팅) 가림 허용.
- 자막 제외 추임새: 아·어·에이·하·씨·아씨·아이씨·에이씨 같은 단독 토큰은 자막에 넣지 않는다. '어?'처럼 반응 의미가 있는 것은 남긴다.
- 강조 글자: 그 시간의 자막 자리에서 자막을 대신한다(같은 문구 두 번 표시 금지). Black Han Sans 190px, 노랑 글씨+검은 외곽선+빨간 바깥 테두리.
- 정보 카드: 왼쪽 위 고정, 화면 글자로 확인한 사실만. 큰 자막과 겹치지 않게.
- 외부 이미지(밈): 사용자 밈 폴더에서만 선택, 자체 제작 그래픽 금지. 최대 900×540, 오른쪽 세로 중앙, 흰 테두리. 게임 UI 가림 허용(밈 우선), 핵심 반응·자막은 가리지 않는다.
