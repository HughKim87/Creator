# 영상 편집 규칙 승격 후보

- 목적: 한 영상에서 발견됐지만 아직 운영 규칙으로 일반화할 수 없는 판단을 보존하고 독립 영상에서 반복 여부를 검토한다.
- 읽는 시점: 새 독립 영상의 완료 회고에서 같은 실패가 반복됐거나 영상 편집 규칙·자동화·skill 승격을 검토할 때.
- 책임: 영상 편집 workflow 유지자가 근거와 재현 결과를 갱신하고, 사용자가 새 지속 규칙·skill 범위를 승인한다.
- 상태: 참고 후보이며 현재 운영 규칙이나 기본 합격값이 아니다.
- 관련 권위: `PROJECT_RULES.md`, `extension/README.md`, `VIDEO_EDITING_WORKFLOW_CONTRACT.md`.

## 승격 gate

후보는 다음 조건을 모두 만족할 때만 기존 규칙 보강 또는 새 규칙으로 승격한다.

1. 두 번째 독립 영상에서도 같은 root cause와 수동 판단이 반복된다.
2. R01~R16의 기존 조건·예외로 해결되지 않는다.
3. task 고유 수치·파일명·프레임을 제거해도 조건과 행동을 설명할 수 있다.
4. `조건 / 행동 / 예외 / 검증`과 보호 데이터가 없는 재현 사례가 있다.
5. 새 규칙이 줄이는 실패와 추가하는 유지 비용을 비교할 수 있다.
6. 정확한 owner와 라우팅 trigger가 있으며 기존 정본을 복제하지 않는다.

## 후보 목록

| ID | 후보 | 현재 보류 이유 | 반복 시 필요한 증거 |
|---|---|---|---|
| CAND01 | 영상별 luma·RMS calibration 절차 | 한 영상 수치는 전역 합격값이 될 수 없음 | 서로 다른 두 영상에서 calibration이 같은 오탐·미탐을 줄임 |
| CAND02 | 장르별 컷 길이·제거율 profile | 고정 길이와 비율이 사건·감정 기능을 대체함 | 장르·목적별 분포와 사용자 승인 결과가 반복됨 |
| CAND03 | 공간 전환 beat template | 고정 요소 개수가 최소 인과 연결을 과잉 규정함 | 서로 다른 공간 편집에서 같은 누락 패턴과 최소 template이 재현됨 |
| CAND04 | 반복 사건 압축 곡선 | 클라이맥스·새 실패는 뒤 사건이 더 길 수 있음 | 기능 tag를 포함한 반복 압축 판정이 독립 영상에서 유효함 |
| CAND05 | 자동 spine coverage 보조 | 의미 적절성을 코드가 자동 승인할 수 없음 | 누락 후보 탐지가 reviewer의 실제 결함 탐지를 반복 보조함 |
| CAND06 | 사용자 XML과 timeline block diff | 두 번째 실제 수정본과 반복되는 비교 비용이 아직 없음 | 범위 승인 무효화와 재작업을 유의미하게 줄이는 diff 사례 |
| CAND07 | 채널 전역 편집 성향 owner | 한 영상 취향과 채널 불변 조건을 구분할 근거 부족 | 독립 영상 여러 건의 사용자 승인에서 동일 선호가 유지됨 |
| CAND08 | Premiere 버전별 호환 profile | 합성 구조 검증만 있고 실제 앱 차이가 미검증 | 실제 import·재생에서 profile별 차이와 fixture가 확인됨 |
| CAND09 | 전용 영상 편집 skill | 현재 규칙·도구의 두 번째 영상 재사용 효과가 미검증 | 반복 수동 orchestration을 줄이고 R01~R16을 안정적으로 수행함 |

## 승격하지 않는 task 사실

백룸 revision 번호, exact frame, 파일명, 절대 경로, 단일 영상의 해시·길이는 후보가 아니라 해당 작업의 상태·증거다. 그대로 규칙으로 승격하지 않는다. 반복되는 추상 실패가 확인될 때만 위 후보의 조건으로 환원한다.

## 사용 결과

- 반복 없음: 후보 상태를 유지하고 새 규칙·자동화를 만들지 않는다.
- 기존 규칙으로 해결: 해당 규칙의 조건·예외·재현 사례만 최소 보강한다.
- 독립 반복과 새 trigger 확인: 정확한 owner와 회귀를 설계해 사용자 승인 후 승격한다.
