## 2. 타겟 시청자 분석

| 시청자층 | 특징 | 이 영상에서 원하는 것 | 편집 반영 |
|---|---|---|---|
| A. 영화 보고 유입된 라이트층 (핵심, 10·20대) | 영화로 백룸을 처음 알았다. 게임은 해 본 적 없을 수 있다 | "영화 속 그 공간에 직접 들어가면 어떤가", 무엇이 무서운지 쉽게 이해 | 장 시작마다 레벨 카드, 규칙을 한 줄로 알려 주는 정보 자막(문 닫으면 못 들어옴, 빛 안에 있어야 함), 엔티티 첫 등장 소개 카드 |
| B. 로어·세계관 팬 | 레벨·엔티티·설정에 진심. 틀린 정보에 민감 | 정확한 이름, 숨은 디테일, 영화·원작과의 연결 | 확인된 정보만 표기, 화면 속 문구·안내문을 짧게 짚어 줌, 영화와 비교하는 플레이어 발언("영화라서 평온하게 볼 수 있었던 거네", "기괴한 느낌은 덜하다") 강조 |
| C. 리액션·예능 소비층 | 스트리머의 쫄보 반응과 허세 반전을 보러 옴. 밈 감각 | 큰소리친 직후 무너지는 장면, 웃긴 한마디 | 반전 대사 강조 자막, 놀람 뒤 짧은 코믹 효과음·줌, "한 시간만" 다짐 카운터 같은 반복 개그 장치 |

세 층은 겹친다. 그래서 원칙은 이렇다.
- **긴장 구간은 원작 팬(B)의 감각**: 효과 없이 게임 소리와 고요를 그대로 둔다. VHS·리미널 질감은 카드·전환에만 쓴다.
- **놀람 뒤와 쉬는 구간은 예능층(C)의 감각**: 강조 자막, 코믹 효과음, 줌으로 웃음을 살린다.
- **이해가 필요한 순간은 라이트층(A)을 위해**: 레벨·규칙·엔티티 정보 자막을 넣는다.

## 3. 후편집 레이어 설계

### 3.1 기본 자막 (전체)
- 모든 발화에 하단 자막. 모바일 무음 시청과 배속 시청 대응.
- 원본 SRT는 시간이 어긋나고 오인식이 있어 그대로 쓰지 않는다. r11 타임라인 기준으로 다시 받아 적고, 고유명사·속어는 사람이 확인한다.
- 비명·"흐어허허"는 글자로 늘어놓지 않는다. 짧게 쓰거나 생략한다.
- 스타일: 흰 글자, 검은 외곽선, 화면 하단 고정. 공포 장면에서 흔들기·붉은 깜빡임은 하지 않는다.

### 3.2 정보 자막과 레벨 카드 (라이트층·로어층)
레벨 카드는 VHS 질감의 짧은 하단 표기(2–3초)로, 원작 Found footage 감성을 살린다. 화면 전체를 덮는 타이틀은 쓰지 않는다.

### 3.3 강조 자막·코믹 효과음·줌 (예능층)
- 쓰는 곳: 놀람이 지나간 뒤, 허세가 무너지는 순간, 웃긴 한마디. 대략 30초에 한 번 이하.
- 쓰지 않는 곳: 위협이 다가오는 빌드업, 추격 중, 승인된 대표본의 긴장 구간.
- 주요 후보 (r11 위치):
  - 2:08 첫 사망 → "적응했습니다" (허세)
  - 3:10 "영화라서 평온하게 볼 수 있었던 거네"
  - 5:01 "어차피 NPC일 뿐이야" → 5:06 "무서운 건 무서운 거지" (바로 무너짐)
  - 6:28 "안 무서워 하나도 안 무섭죠?"
  - 10:18 문 뒤에서 도발 → "아 근데 무서워"
  - 11:10 "빼꼼은 못 보는구나" → 사망
  - 14:45 "혼자 생쇼하고 있었네" (가장 큰 웃음 후보)
  - 16:19 "문 열어주세요 사장님 / 불 켜주세요"
  - 17:26 "밤이 되었습니다, 마피아는…"
  - 18:57 출구 지나침
- **"한 시간만" 다짐 카운터**: 6:54 "한 시간만 하고 끌래요" → 11:46 이후 "한 시간만 하고 끄고 싶었는데" → 12:48 "이번 스테이지만" → 14:22 "한 스테이지만 더" → 20:31 "끄고 싶습니다". 같은 위치(화면 상단 구석)에 작은 카운터를 띄워, 계속 미루는 반복 개그를 시각화한다. 영상 전체를 잇는 스파인 장치이자 예능 포인트.
- 줌: 반응 직후 1.1–1.2배 정도의 짧은 펀치인만. 긴장 구간에서는 쓰지 않는다.

### 3.4 오디오
- 음성: 노이즈 정리, 약한 압축으로 고르게, 게임 소리와 겹치는 대사는 게임 소리를 살짝 낮춤.
- 전체 음량: YouTube 기준(약 -14 LUFS)에 맞춤. 비명 피크 제한.
- 배경음악: 긴장·탐색 구간은 넣지 않음(게임 환경음이 공포를 만든다). 퍼즐 해결·코믹 구간·엔딩에만 낮게.
- 효과음: 게임이 이미 낸 놀람 소리에 덧대지 않는다. 코믹 효과음은 강조 자막과 함께 놀람 뒤에만.
- 음원 출처: YouTube 오디오 보관함 우선. 라이선스 유형(표기 필요 여부)을 기록한다.

### 3.5 화면 질감·전환
- VHS·노이즈 질감은 레벨 카드·오프닝 타이틀·챕터 전환에만. 게임 화면 전체에 씌우지 않는다(화면이 어두워 식별이 떨어짐).
- 장 전환은 현재 하드컷 유지. 레벨 이동 지점만 0.3–0.5초 노이즈 전환 후보.

### 3.6 패키징
- 도입 15초: 이미 시작하는 인게임 도입 영상 위에 제목 오버레이와 첫 공포 예고를 얹는다. 앞부분 삭제 지시(콜드 오픈·동기 설명이 루즈함)를 존중해 길이는 늘리지 않는다. 별도 3–5초 티저(예: Smiler 등장 → "한 시간만 하고 끌래요")는 선택안.
- 썸네일 후보: 노란 복도 또는 Smiler 얼굴 + 큰 글자("한 시간만 하고 끌래요" 류). 원본 프레임에서 후보 6장 추출 후 선택.
- 제목 후보: 영화 유입 키워드(백룸, 영화 백룸) + 체험 약속.
- 챕터: 레벨 카드 위치 그대로 YouTube 챕터로 사용.
- 엔드스크린: 마지막 검은 화면 구간(21:34~)에 맞춰 길이 확보 필요 여부 결정.

## 4. 작업 방식과 순서

에이전트가 만들 수 있는 것과 Premiere에서 사람이 해야 하는 것을 나눈다.

| 단계 | 내용 | 에이전트 산출물 | 사용자/Premiere |
|---|---|---|---|
| 0 | 결정 | 이 문서 | 결정 대기 항목(§5) 선택 |
| 1 | 기본 자막 | r11 타임라인 기준 자막 파일(SRT). 정확한 받아쓰기를 위해 음성 인식 도구가 필요(아래 참고) | Premiere 캡션으로 가져오기, 스타일 적용 |
| 2 | 정보·강조 자막 위치 | 위치·문구가 담긴 마커 XML(Premiere 시퀀스 마커로 가져오기) + 문구 목록 | 마커를 보며 그래픽 자막 배치 |
| 3 | 이미지 자산 | 레벨 카드·엔티티 카드·다짐 카운터 PNG(투명 배경), 오프닝 타이틀 | 트랙에 배치 |
| 4 | 효과음·음악 큐시트 | 위치별 효과음·음악 큐 목록(음원은 YouTube 오디오 보관함에서 선택) | 음원 배치, 믹싱 |
| 5 | 오디오 마감 | 음량 기준·처리 순서 체크리스트 | 음성 처리, 라우드니스 맞춤 |
| 6 | 패키징 | 썸네일 후보 프레임, 제목·설명·챕터 문안 | 썸네일 제작, 업로드 |

진행 방식: 지금까지의 교훈대로 처음 5분(0:00–5:24)에 모든 레이어를 먼저 적용한 샘플을 만들어 확인받고, 방향이 맞으면 전체에 같은 규칙을 적용한다.

필요한 도구: 정확한 자막을 위해 음성 인식(Whisper 계열)이 필요하다. 예전 작업에 쓰던 Windows용 로컬 Whisper(medium)가 있었고, 이번 세션 환경에는 설치돼 있지 않다. 설치·실행은 사용자 승인이 필요하다.

## 5. 결정이 필요한 항목

1. 자막 범위: 전체 발화 자막 + 강조 자막(권장) / 강조 자막만
2. 효과음·음악 강도: 긴장 구간 무음, 놀람 뒤만 예능 효과(권장) / 예능 효과 더 많이 / 최소
3. 오프닝: 제목 오버레이만(권장, 길이 유지) / 3–5초 티저 추가
4. 레벨 카드 스타일: VHS 하단 표기(권장) / 깔끔한 텍스트
5. 음성 인식 도구 설치 승인(자막 정확도)
