# 대사 기반 영상 기획

이 스킬은 워크플로우의 **영상 기획 단계**를 라우팅한다.
상세 절차의 단일 기준은 `planning_research/planning_stage_spec_2026-07-06.md`다.
강제 단계 순서와 승격 조건의 정본은 `docs/WORKFLOW_CONTRACT.json`이다.

## 입력

- `outputs/06_analysis/CURRENT.json`이 가리키는 승인 데이터 분석 기준본
- 데이터 근거지도의 사건·감정·화면·음성·시청자 관심·반증·재검증 ID
- 안정된 `source_id`와 원본 지문·원본 시간 기준
- 원본 자막 또는 전사와 타임코드 신뢰도
- 사용자가 정한 대상 시청자 가설, 톤, 제외 조건
- 기존 기획 사용 여부: 기본값 `비교 자료로만 사용`

데이터 분석이 승인되지 않았거나 원본 자막 기준이 없으면 영상 기획을 시작하지 않는다.
기존 기획·컷리스트·XML·러프컷은 근거 기준본이 아니며 새 기획을 정당화하는 입력으로 쓰지 않는다.

## 출력

영상 기획서는 아래 항목을 포함한다.

- 산출물 상태와 승인 상태
- `source_id`, 원본 지문, 원본 시간 기준
- `baseline_version`, `changed_ranges`, `supersedes`, `current_pointer`
- 승인 데이터 분석 기준본과 사용한 근거 ID
- 시청자 약속
- 후보 메시지 2~3개 비교와 반례
- AI 권고 중심 메시지 한 개
- 원본 대사·화면 근거 연결 스파인
- 캐릭터 변화와 긴장-이완 구조
- 포함·축소·제외·재검증 기준
- 자체 레드팀 검토
- 대표 편집 단계가 오디오 신호·편집 의미·연속 A/V로 나눠 확인할 항목
- `approved_for_calibration` 상태와 사용자 판단 시점이 대표 샘플 이후라는 표시

## 게이트

다음 조건을 모두 충족한 하나의 권고안만 사용자에게 제시한다.

1. 시청자 약속이 승인된 시청자 관심 근거와 연결된다.
2. 중심 메시지는 한 개이며 모든 조각이 원본 대사 또는 화면 근거로 추적된다.
3. 캐릭터의 시작·변화·끝이 원본 순서로 정의된다.
4. 모든 스파인 비트에 데이터 근거 ID, 원본 시간, 이야기 기능, 제외 시 손실이 있다.
5. 화면이 약한 설명은 설명 근거로만 쓰며 관련 없는 화면으로 의미를 주입하지 않는다.
6. 반례·약점·재검증 항목을 무시해야만 성립하는 메시지는 탈락한다.
7. AI 자체 레드팀 검토를 통과한다.
8. G1~G7을 통과하면 `approved_for_calibration`로 승격한다. 이는 제한된 대표 샘플만 허용하며 전체 편집 기준본 승격은 아니다.

## 중단 조건

- 데이터 분석 게이트가 닫혀 있다.
- 원본 영상·자막·`source_id`·현재 분석 기준본이 불명확하다.
- 재검증 근거를 사실로 단정해야만 메시지가 성립한다.
- 반박 근거를 누락해야만 메시지가 성립한다.
- 컷리스트·XML·과거 편집 결과가 새 메시지를 끌고 있다.
- 같은 기획 방향이 두 번 거절됐다.

## 다음 단계 전달물

대표 편집 단계에는 아래만 넘긴다.

- AI 자체 검토를 통과한 임시 시청자 약속과 중심 메시지 한 개
- `source_id`, 원본 지문, 원본 시간 기준
- 데이터 분석 기준본과 사용 근거 ID
- 근거 연결 스파인과 캐릭터 변화
- 포함·축소·제외 기준
- 문장 단위 보존이 필요한 발화
- 실제 AV 재생이 필요한 재검증 항목
- 훅·추격·소리·발화 경계에 대한 편집 검증 질문
- `outputs/05_planning/CURRENT.json`과 워크플로우 게이트 상태
- 사용자 창작 방향 판단 시점: AI가 원본 음원·자막·등록 화면 근거를 범위별로 자체 검증한 뒤

## AI가 확정하지 말 것

- 사용자의 최종 창작 방향 승인과 전체 편집 확장 여부
- 컷 경계와 최종 컷리스트
- XML, EDL, 러프컷
- 실제 AV 검증 전 훅·추격·소리 인과의 최종 판정
- 업로드 판단

## 좋은 요청 예시

```text
승인된 데이터 분석과 원본 대사만 사용해 시청자 약속과 중심 메시지 한 개를 권고해줘.
모든 스파인 비트에 근거 ID와 반례를 붙여 대표 캘리브레이션 입력으로 넘겨줘.
```

```text
기존 기획은 비교만 하고 승인 데이터 근거에서 통합 기획을 다시 만들어줘.
화면이 약하거나 실제 재생이 필요한 부분은 재검증으로 남겨줘.
```
