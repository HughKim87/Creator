# 게임 트렌드 리서치

이 스킬은 단순 인기 게임 순위가 아니라, 대상 채널에서 영상 소재로 만들 만한 게임과 이슈를 고른다.

## 입력

- 조사 기준일과 기간
- 대상 플랫폼: PC, 모바일, 콘솔, 종합
- 대상 시장: 한국 기본
- 채널 성향: 운영 논란, 배신감, 구조 해부, 직접 플레이 가능성
- 제외할 게임, 장르, 이슈
- 출력 개수

입력이 없으면 아래 기본값을 사용한다.

- 기간: 최근 7일 + 최근 30일 비교
- 시장: 한국
- 출력: 추천 후보 5개, 보류 후보 5개, 제외 후보 5개

## 조사 출처

| 축 | 우선 출처 | 보조 출처 | 주의 |
|---|---|---|---|
| 검색 수요 | Google Trends, 네이버 DataLab | 검색 자동완성, 뉴스량 | 상대 지표다. 절대 검색량처럼 말하지 않는다. |
| 유튜브 수요 | YouTube 검색 결과, YouTube Data API | 최근 영상 조회수, 제목 반복 키워드 | 조회수만으로 소재성을 확정하지 않는다. |
| 방송 수요 | 치지직, SOOP, Twitch 카테고리/게임 랭킹 | Weflview 같은 통합 랭킹 | 비공식 출처는 `약한 근거`로 표시한다. |
| 이슈성 | 공식 공지, 패치노트, 스팀/스토어 공지, 게임 뉴스 | 커뮤니티 반응 | 커뮤니티 반응은 대표 여론으로 단정하지 않는다. |
| 채널 적합도 | 대상 채널 방향, 직접 경험 가능성 | 과거 영상 톤 | AI가 최종 선택하지 않는다. |

## 조사 절차

1. 후보 풀을 넓게 만든다.
   - 검색 상승 게임
   - 방송 시청자 상승 게임
   - 최근 출시/업데이트/논란 게임
   - 커뮤니티에서 반복 언급되는 게임

2. 각 후보의 근거를 분리한다.
   - 검색 수요
   - 유튜브 수요
   - 방송 수요
   - 이슈 촉발점
   - 대상 채널 적합도

3. 약한 근거를 표시한다.
   - 비공식 랭킹
   - 단일 커뮤니티 반응
   - 조회수는 높지만 게임명이 아닌 크리에이터 팬덤 영향
   - 검색량은 높지만 영상 각도가 불명확한 경우

4. 점수화한다.

| 항목 | 점수 | 기준 |
|---|---:|---|
| 최신성 | 0~5 | 최근 7일 안에 명확한 사건이나 상승이 있는가 |
| 검색 수요 | 0~5 | Google/Naver 상대 지표나 검색 반복성이 있는가 |
| 유튜브 수요 | 0~5 | 최근 영상 성과와 제목 키워드 반복이 있는가 |
| 방송 수요 | 0~5 | 라이브 시청자나 카테고리 상승이 있는가 |
| 이슈 밀도 | 0~5 | 논란, 업데이트, 유저 반응, 운영 변화가 설명 가능한가 |
| 채널 적합도 | 0~5 | 채널 고유 관점이나 배신감 서사가 가능한가 |
| 제작 가능성 | 0~5 | 직접 플레이, 자료 확보, 영상화가 현실적인가 |

5. 판정을 나눈다.
   - `추천`: 지금 영상화 검토 가능
   - `보류`: 수요는 있으나 각도나 근거가 부족
   - `제외`: 인기와 무관하게 대상 채널 소재로 부적합

## 게이트

다음 조건을 모두 통과해야 2단계 채널 기획으로 넘긴다.

1. 추천 후보마다 최소 2개 이상의 서로 다른 근거 축이 있다.
2. 기준일, 조사 기간, 출처가 표시되어 있다.
3. 상대 지표와 절대 수치를 구분했다.
4. 추천, 보류, 제외가 분리되어 있다.
5. 대상 채널 적합도와 제작 가능성이 따로 평가되어 있다.
6. 사용자가 최종 소재를 선택해야 한다고 표시되어 있다.

## 중단 조건

- 출처가 1종류뿐이면 추천 후보로 확정하지 않는다.
- 검색량이나 조회수만 있고 영상 각도가 없으면 보류한다.
- 비공식 출처만 있는 경우 `약한 근거`로 표시하고 단정하지 않는다.
- 사용자가 제외한 게임이나 장르가 후보에 들어가면 멈추고 확인한다.
- 최신성 기준일을 알 수 없으면 결과를 내지 않는다.

## AI가 확정하지 말 것

- 최종 소재 선택
- 최종 제목과 썸네일
- 진행자가 실제로 플레이할지 여부
- 논란의 옳고 그름
- 커뮤니티 반응을 전체 유저 여론으로 단정하는 것

검색 수요, 유튜브 수요, 방송 플랫폼 수요, 커뮤니티 이슈를 분리해서 보고,

```

```
