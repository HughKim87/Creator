# 유튜브 대본 구성

이 스킬은 2단계에서 승인된 채널 콘셉트를 대본 구조로 바꾼다.
대사를 실제로 완성하기보다, 주장, 근거, 장면 목적, 시청자 유지 포인트를 먼저 고정한다.

## 입력

- 2단계 채널 기획 산출물
- 사용자가 승인한 콘셉트
- 핵심 주장 후보
- 사용할 근거와 아직 약한 근거
- 직접 플레이 여부
- 영상 길이 목표
- 피해야 할 표현이나 톤

## 작업 절차

1. 승인된 콘셉트를 확인한다.
   - 사용자가 승인한 핵심 주장만 기준으로 삼는다.
   - 승인되지 않은 제목/썸네일 방향을 대본 기준으로 쓰지 않는다.

2. 주장을 논리 흐름으로 분해한다.
   - 도입: 왜 지금 봐야 하는가
   - 문제 제기: 무엇이 이상하거나 불만인가
   - 근거: 어떤 사례와 자료가 있는가
   - 직접 경험: 진행자가 말할 수 있는 범위는 어디까지인가
   - 구조 분석: 시스템, 운영, 과금, 성장, 매칭 중 무엇이 문제인가
   - 결론: 시청자가 어떤 판단을 가져가야 하는가

3. 장면 목적을 붙인다.
   - 각 파트가 보여줄 화면, 자료, 플레이 장면, 자막 근거를 정한다.
   - 화면 근거가 없으면 말로만 단정하지 않는다.

4. 시청 유지 위험을 표시한다.
   - 도입이 늦어지는 구간
   - 근거 없이 감정만 강한 구간
   - 같은 주장 반복
   - 플레이 화면과 말이 따로 노는 구간

5. 다음 단계 전달물을 만든다.
   - 4단계 자막/자료 정리에 필요한 대본 구조
   - 촬영 완료본이면 5단계 대사 기반 기획으로 넘길 확인 질문

## 게이트

다음 조건을 모두 통과해야 4단계 자막 생성/정리 또는 촬영/녹화 준비로 넘긴다.

1. 2단계 승인 콘셉트를 기준 입력으로 사용했다.
2. 핵심 주장이 도입부터 결론까지 이어진다.
3. 각 파트에 목적과 근거가 있다.
4. 직접 경험한 내용과 자료 기반 주장이 구분되어 있다.
5. 제목/썸네일이 약속한 내용을 본문이 실제로 다룬다.
6. 사용자가 대본 흐름을 승인해야 한다고 표시되어 있다.

## 중단 조건

- 2단계 콘셉트가 승인되지 않았으면 대본을 만들지 않는다.
- 근거 없는 비판 문장이 핵심 주장으로 들어가면 멈추고 근거를 요청한다.
- 직접 플레이하지 않은 경험을 1인칭 체험처럼 쓰면 멈춘다.
- 영상에서 보여줄 수 없는 장면을 핵심 근거로 삼으면 보류한다.
- 사용자가 흐름을 거절하면 같은 구조로 문장만 바꾸지 않는다.

## AI가 확정하지 말 것

- 최종 대본 문장
- 최종 톤
- 실제 경험 여부
- 게임사나 개발자 의도
- 최종 제목/썸네일
- 업로드 여부
