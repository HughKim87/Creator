# 김실버 유튜브 프로젝트

- 목적: 사용자가 프로젝트의 현재 상태, 문서 입구, 안전 경계와 다음 승인 단계를 빠르게 확인할 수 있게 한다.
- 사용 시점: 프로젝트를 처음 열거나 현재 구축 상태와 사용 방법을 확인할 때 사용한다.
- 작성·수정 주체: 에이전트가 유지하고, 정책·범위 변경은 사용자가 승인한다.
- 언어: 한국어.
- 저장 위치와 연결 관계: 프로젝트 루트. [사용자 가이드](docs/user/GUIDE.md), [문서 지도](docs/agent/DOCUMENT_MAP.md), [현재 인수인계](SESSION_HANDOFF.md), [현재 설계 제안](docs/reports/2026-07-20_R-1.1_지식_시스템_설계_보정.md)으로 연결한다.

## 현재 상태

프로젝트의 공통 규칙과 문서 기반을 새로 구축한 상태다. 이전 구현은 `backup/`에 읽기 전용 역사 자료로 보존돼 있으며 활성 프로젝트의 실행 기반이 아니다.

현재 포함된 범위:

- 에이전트 시작 라우터와 상시 공통 규칙
- 문서별 역할·권위·언어·사용 시점
- 공통 작업·검증·승인 절차
- 지식 기록, 검색, 검토 시스템의 구현 전 계약
- 다음 세션을 위한 단일 인수인계 문서
- 사용자 승인으로 생성한 첫 수동 문제·실패·해결 사례 1건

아직 포함되지 않은 범위:

- 원본 작업 기록 writer와 자동화된 지식 레코드 시스템
- JSON Schema validator
- SQLite FTS5 검색 인덱스
- 컨텍스트 패키지 생성기
- 벡터 검색, 지식 그래프 DB, Obsidian 설정
- 기존 영상 제작 기능의 선택 이식

현재는 중복 문서의 권위와 보존 경로를 정상화하고 R-1.1 설계를 채택한 상태다. 다음 새 세션은 승인된 R-2A 범위만 구현한다.

## 안전 경계

- `backup/`은 수정하지 않는다.
- 사용자가 정확한 작업이나 산출물을 지정하지 않으면 `inputs/`, `outputs/`를 열거하거나 읽지 않는다.
- 사용자 보고는 한국어, 에이전트 운영 문서는 영어로 관리한다.
- 단계형 작업은 단계 보고와 사용자 승인 사이에서 멈춘다.
