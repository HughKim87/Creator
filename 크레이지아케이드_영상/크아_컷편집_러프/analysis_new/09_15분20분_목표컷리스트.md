# 09 15~20분 목표 컷리스트

목표:
- 플레이 영상으로 자연스럽게 볼 수 있는 길이까지 줄인다.
- 부정적인 고인물/캐시템 분석은 덜어낸다.
- "비슷한 실력끼리 하니까 재밌다"는 흐름을 가장 강하게 남긴다.

## 과감히 뺀 컷

| 제외한 컷 | 이유 |
|---|---|
| 고레벨 상대 의외 승리 | 재미는 있지만 전체 주제에서 필수는 아님 |
| 꼬물이 주고받기 | 여자친구 대결/몬스터 모드와 역할이 겹침 |
| 방탈출/탈출맵 | 길고 규칙 이해가 늦어져 흐름이 늘어짐 |
| 캐릭터/아이템 분석 | 리뷰 영상용으로 따로 빼는 편이 좋음 |
| 매칭 실패 반복 | 초반에 짧게만 보여주면 충분 |

---

## 최종 흐름

1. `훅`: 3인 플레이에서 0.1초 차이 승리
2. `이유`: 크아 서비스 종료라 추억으로 접속
3. `갈등`: 막상 해보니 고인물에게 털림
4. `목표`: 사람 상대로 한 판만 이기고 싶어짐
5. `전환`: 비슷한 실력 상대를 만나 재미가 생김
6. `확장`: 여자친구와 1대1로 티격태격
7. `확장`: 3명이 몬스터 모드 하며 같이 노는 재미
8. `정리`: 실력 비슷해야 재밌다는 결론
9. `엔딩`: 3명이 하니까 게임 맛이 난다는 소감
