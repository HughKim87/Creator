# 08 압축 컷리스트 v1

목표:
- 1차 컷리스트의 큰 흐름은 유지한다.
- 하지만 그대로 쓰면 너무 길기 때문에, 각 구간을 "보여줄 핵심"만 남긴다.
- 한 판의 결과가 중요한 구간은 결과까지 살린다.
- 반복되는 패배, 설정, 방 찾기, UI 탐색은 줄인다.

## 구성 요약

이 편집안은 "크아가 망했다"보다 "크아는 언제 재밌어지는가"를 중심으로 간다.

흐름:
1. 재미있는 결과를 먼저 보여준다.
2. 왜 이 게임을 켰는지 설명한다.
3. 초반에는 고인물과 매칭 문제 때문에 막힌다.
4. 비슷한 실력 상대를 만나면서 재미가 살아난다.
5. 여자친구와 하면서 티격태격하는 놀이가 된다.
6. 3명이 하니 더 게임 맛이 난다.
7. 결론은 실력 비슷한 사람끼리 해야 재밌다는 것.
