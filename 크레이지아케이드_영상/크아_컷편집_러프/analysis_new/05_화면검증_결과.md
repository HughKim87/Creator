# 05 화면 검증 결과

확인 방식:
- 자막+음성으로 좁힌 10개 후보만 화면 시트로 확인했다.
- 원본 영상 복사/변환은 하지 않았다.
- 이 단계는 편집 확정이 아니라, 컷 후보를 `사용/부분사용/보류`로 나누는 단계다.

---

|---|---|---|---|

## 현재 편집 방향

플레이 영상 구조는 다음이 가장 자연스럽다.

1. C01을 앞에 둬서 재미있는 결과를 먼저 보여준다.
2. C02로 돌아가서 처음엔 고인물에게 털렸다는 갈등을 만든다.
3. C03-C05로 비슷한 실력 상대를 만나며 재미가 살아나는 흐름을 보여준다.
4. C06-C08로 여자친구/3인/협동 플레이를 통해 크아의 놀이성이 살아나는 흐름을 만든다.
5. C09-C10으로 "실력이 비슷해야 재밌다", "3명이 하니 게임 맛이 난다"로 마무리한다.
