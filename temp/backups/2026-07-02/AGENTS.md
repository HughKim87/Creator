## Project hierarchy

이 프로젝트(김실버유튜브)는 상위 프로젝트 `Building WorkFlow`의 하위 프로젝트다.
상위 프로젝트의 공통 규칙이 먼저 적용되고, 이 폴더의 문서는 그 하위 지침이다.

적용 순서: 상위(Building WorkFlow) 공통 규칙 → `00_공통_작업원칙.md` → `01_유튜브_제작_워크플로우.md` → `skills/*/SKILL.md`

## Project workflow structure

이 프로젝트의 유튜브 작업은 다음 문서를 우선 기준으로 삼는다.

1. `00_공통_작업원칙.md`
   - 원본 보호, 파일 생성/삭제, 의도 확인, 중복 방지 규칙

2. `01_유튜브_제작_워크플로우.md`
   - 전체 작업 순서와 단계별 스킬 호출 기준

3. `skills/*/SKILL.md`
   - 각 작업을 실제로 수행하는 독립 스킬

워크플로우는 스킬의 세부 절차를 반복하지 않고, 스킬은 전체 워크플로우를 반복하지 않는다.
