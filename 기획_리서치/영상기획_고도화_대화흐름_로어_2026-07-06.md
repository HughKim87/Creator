# 영상 기획 고도화 — 대화 흐름 연결 + 게임 로어 설계 (2026-07-06)

목적: 확정 구성안(4막, 2026-07-05)을 유지하면서, ① 컷 사이 **대화가 자연스럽게
이어지는지 전수 감사**, ② **게임·영화 배경지식**을 자막·챕터에 심어 서사를
보강한다. 컷 취사 판정은 `06_무음_판정표`가 담당 — 이 문서는 연결과 의미 설계.

## 1. 게임 배경지식 리서치 (자막·기획에 쓸 재료)

### 영화 쪽 (업로드 타이밍의 근거)

- 영화 "Backrooms"는 유튜버 케인 픽셀스(Kane Parsons)의 원작 시리즈를 A24가
  영화화한 것. **2026-05-29 북미 개봉, 6월 말 기준 글로벌 $3.3억 — A24 역대
  최고 흥행작.** 7월 3일 확장판 재개봉으로 화제 지속 중.
- 게임의 VHS풍 인트로 시네마틱은 케인 픽셀스 원작 파운드푸티지의 오마주 —
  김실버의 "영화 처음 시작할 때 그 장면 보는 것 같은데"(5:14)가 정확히 이 지점.
  → 인트로 시네마틱에 자막 부연 1줄: *"영화 원작(케인 픽셀스)의 그 장면 맞습니다"*

### 게임 쪽 (그가 겪은 일들의 정체 — 로어 자막 재료)

| 그가 한 말/겪은 일 | 게임 로어 (사실 확인) | 자막 활용 |
|---|---|---|
| "문을 열고 오진 않네"(37:34), "인식을 못하네 문 닫으면"(39:15) | Level 1의 엔티티 **스킨 스틸러** — 문을 열지 못하고, 방에 숨으면 피할 수 있음 | 로어 자막: "엔티티: 스킨 스틸러 — 문은 못 엽니다" → 그의 '학습'이 진짜 공략임을 인증 |
| "양팔 벌리고 미친듯이 달려와"(35:40) | 스킨 스틸러의 돌진 모션 | "저 달리기가 공식입니다" 류 예능 자막 |
| "아몬드물?"(28:32) | **아몬드 워터** — 백룸 세계관의 정신력(sanity) 회복 아이템, 원작 크리피파스타부터 등장 | 로어 자막: "아몬드물 = 백룸 세계관의 이온음료" |
| M.E.G. 테이프 종료 화면 (사망 시) | **M.E.G. = Major Explorer Group**, 백룸 탐사대 — 플레이 기록이 '탐사 테이프'라는 설정 | 사망 카운터를 "M.E.G. 테이프 n호 종료"로 통일 — 예능 장치+로어 |
| "0레벨이였어"(26:44) → 주차장 → 파이프 | Level 0(노란 로비) → Level 1(주차장, 열쇠 4개) → Level 2(파이프, 질주 구간) | 챕터 자막: Level 0 / Level 1 / Level 2 (기존 설계 유지, 명칭 공식화) |
| "누가 들어오면 개무섭겠다"(4:43) | 크로스플레이 난입 가능 설정 | 솔로 설정 컷(03)의 긴장을 로어로 뒷받침 |

## 2. 대화 흐름 전수 감사 (컷 경계 41곳)

기준: 앞 컷의 마지막 문장 → 뒤 컷의 첫 문장을 이어 읽었을 때 대화로 성립하는가.

### 자연스러움 ✓ (그대로)

01a→01b→01c(시연 완료) · 05→06(공유 경계) · 07→08→09(불안 고조) · 11→12 ·
13→14(비명→웃음) · 14→15→16→17(소감 체인) · 17→18("차분하게"→"원래 못해요"
아이러니) · 18→19→20(로어 체인) · 22~26(추격 아크) · 27→28(공유 경계) ·
30→31→32 · 33→34→35 · 35→36("안도 이유"→"선행학습" 논리 연결) · 37→38→39→40 ·
41→42 · 42→43(L컷 지시 유지)

### 보정 필요 5곳 (v11 반영 제안)

1. **06 끝 (7:30)** — "…아무도 없다는 걸 눈으로 보고 있으니까"에서 끊김(뒤 원문은
   사운드 조절 방송멘트라 삭제가 맞음). 술어가 반쪽 느낌 → **끝점을 7:28.3
   "…없다는 걸"로 당기거나**(문장 완결), 현행 유지 시 다음 컷을 0.5s 여유로 받기.
   → 권장: 7:29.7 유지 + 07로 하드컷 (원 기획 v5 복원 취지 존중, 파형 스냅)
2. **09→10 (11:28→13:01)** — 로어 설명 직후 "아씨 왜 이렇게 달리기…"가 갑툭튀.
   앞 원문 12:54.2 "그리고 다른 공간에 한번 찾으러 가봅시다"가 브릿지 문장.
   → **10 시작을 12:54.2로 확장** (+7s, 문장 완결 + 대화 연결 동시 해결)
3. **21 내부 (29:31.5 테이프)** — 정면조우 중 사망 사실이 화면에만 있음.
   → 사망 카운터 자막 "M.E.G. 테이프 2호 종료" 삽입으로 사건 명시 (편집 불변)
4. **26→27 (43:54→44:25)** — 사망 직후 → 영화 감상평, 톤 점프.
   → 자막 브릿지: *"사망 김에 잠깐 영화 얘기"* (03 자막 시트에 추가)
5. **28→30 (45:15→48:35)** — 29 삭제로 감상 토크→제어판 직결.
   → 챕터 자막 "다시 Level 1 공략"을 30 머리에 (29의 기능을 자막이 대체 — 삭제 유지)

### 사망 카운터 정리 (화면 실측으로 확정된 사망 지점)

테이프 화면 실측: ① 14:10(첫 사망 — 찐텐 비명 판) ② 29:31(정면조우)
③ 43:41(훅/26 사망) ④ 65:44 부근(몽타주2 "또 죽었죠") ⑤ 73:00(몽타주4)
⑥ 74:45(무한복도) → **03 자막 시트의 사망 카운터를 이 6곳 기준으로 재검증 필요**
(기존 시트는 컷 번호 기준 — v11 컷 번호 변동 없음, 위치만 대조)

## 3. 결론

- 확정 구성안(4막·콜백 체인·오픈루프 훅)은 그대로 유효 — 재배열 불필요.
- 컷 취사: 06_판정표대로 (신규 컷 +26s 제거, 테이프 화면 1곳 복원).
- 이 문서의 보정 5곳 중 **편집 변경은 2건**(06 끝점, 10 머리 확장), 나머지 3건은
  자막 작업(03 시트 갱신)으로 해결.
