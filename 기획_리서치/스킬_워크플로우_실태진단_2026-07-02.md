## 적용한 개선 (C. 편집 파이프라인 강화, 2026-07-02)

1. `gameplay-video-analysis`에 "실행 도구" 섹션 추가
   - 자막: 기존 srt Read, 신규 생성은 Whisper 스크립트 참조
   - 음성 반응: ffmpeg astats 기반 1초 단위 RMS 명령
   - 화면 검증: `video-watch` 스킬 구간 추출 명령 (산출물은 `temp/video-watch/`)
2. `premiere-editing-export`에 러프컷 초안 기능 추가
   - `scripts/make_roughcut.py`: 컷리스트 CSV → 구간 재인코딩 → 이어붙인 초안 mp4
   - 원본 무수정·기존 파일 덮어쓰기 금지 내장
3. `01_유튜브_제작_워크플로우.md` 6단계 완료 기준에 러프컷 초안 옵션 반영
4. (7/2 선행 작업) `video-watch` 스킬 신설 — 프레임 추출 + 전사로 Claude가 영상을 직접 봄
