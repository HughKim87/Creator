# 스킬 개선 및 신규 스킬 검토안

작성일: 2026-06-26  
목적: 오늘 김실버 유튜브 채널 분석 대화에서 드러난 문제를 바탕으로, 기존 스킬을 어떻게 개선할지와 새로 만들 만한 스킬이 무엇인지 검토한다.

---

## 1. 오늘 대화에서 드러난 핵심 문제

오늘 분석 과정에서 가장 큰 문제는 다음이었다.

> 채널 분석과 콘텐츠 방향성은 봤지만,  
> “지금 게임 유튜브에서 사람들이 실제로 무엇을 궁금해하는가”를 처음부터 충분히 조사하지 않았다.

사용자가 지적한 핵심은 정확했다.

- 다른 유튜버의 장점을 가져오는 것만으로는 부족하다.
- 내 채널과 나 자신에 대한 분석이 빠지면 양산형 콘텐츠가 된다.
- 그런데 내 성향만 봐도 부족하다.
- 영상 기획은 현재 사람들이 궁금해하는 게임, 유행하는 게임, 눌러보고 싶은 게임에서 시작해야 한다.
- 유튜브 인기 급상승, 유튜브 게임 홈, 최근 검색 결과, 방송 랭킹, 커뮤니티 이슈까지 함께 봐야 한다.

따라서 앞으로는 다음 순서가 필요하다.

1. 현재 유튜브 게임판에서 뜨는 게임을 먼저 찾는다.
2. 그 게임들이 왜 클릭되는지 확인한다.
3. 방송 플랫폼과 커뮤니티 반응으로 현재성을 검증한다.
4. 그중 김실버 채널과 맞는 게임만 남긴다.
5. 남들이 이미 하는 방식이 아니라 김실버식 관점으로 재포장한다.

## 2. 기존 스킬 개선 필요성

### 2.1 `youtube-channel-coach` 개선 필요

현재 역할:

- 유튜브 채널 분석
- 최근 영상/인기 영상 확인
- 제목, 썸네일, 조회수 패턴 분석
- 채널 방향성 제안

오늘 드러난 부족한 점:

- 채널 내부 분석에 치우칠 수 있다.
- 현재 유튜브 게임 트렌드 확인이 필수 단계가 아니다.
- 영상 기획 제안 전에 “지금 사람들이 어떤 게임을 궁금해하는가”를 먼저 보도록 강제하지 않는다.
- 유튜브 인기 급상승, 게임 홈, 최근 검색 조회수, 방송 랭킹, 커뮤니티 이슈를 한 흐름으로 묶지 않는다.

개선 방향:

`youtube-channel-coach`에 아래 규칙을 추가하는 것이 좋다.

```markdown
### 현재 유튜브 게임 트렌드 확인

영상 기획 제안을 포함하는 채널 분석에서는 채널 내부 데이터만으로 결론을 내리지 않는다.
반드시 다음 외부 수요 데이터를 먼저 확인한다.

1. 유튜브 게임 홈 / 인기 급상승
2. 유튜브 최근 검색 결과의 조회수와 업로드 시점
3. 치지직/SOOP 방송 카테고리 랭킹
4. Google Trends 또는 검색 수요
5. 게임 커뮤니티/뉴스 이슈

그 뒤, 현재 뜨는 게임 후보 중 채널 정체성과 맞는 것만 남긴다.

출력할 때는 반드시 다음 질문에 답한다.

- 지금 사람들이 이 게임을 왜 궁금해하는가?
- 이미 큰 채널들이 어떤 각도로 다루고 있는가?
- 이 채널은 남들과 다른 어떤 질문을 던질 수 있는가?
- 이 소재가 단발 조회수로 끝나는가, 채널 정체성을 강화하는가?
```

추천 출력 항목:

```markdown
## 현재 트렌드와 채널 적합도

| 게임/이슈 | 현재 수요 | 경쟁 강도 | 채널 적합도 | 추천 여부 |

## 지금 찍을 영상

1. 제목
   - 왜 지금인가:
   - 왜 이 채널인가:
   - 근거:
   - 피해야 할 점:
```

### 2.2 `game-ranking-kr` 개선 필요

현재 역할:

- 한국 인기 게임 랭킹 확인
- 치지직/SOOP 시청자 수 확인
- Google Trends 기반 검색 수요 확인
- 크리에이터 관점의 게임 순위 제공

오늘 드러난 부족한 점:

- 유튜브 검색 결과의 최근 조회수 확인이 빠져 있다.
- 유튜브 게임 홈/인기 급상승 확인이 빠져 있다.
- 방송 인기와 유튜브 클릭 수요를 구분하지 않는다.
- 월드컵, 토크, 스포츠 같은 비게임/이벤트 카테고리를 강하게 필터링하지 않는다.
- 특정 채널 적합도 평가가 부족하다.

개선 방향:

`game-ranking-kr`는 단순 게임 인기 순위가 아니라, “게임 영상 소재 랭킹”으로 확장해야 한다.

추가할 단계:

```markdown
### 유튜브 클릭 수요 확인

방송 랭킹만으로 게임 영상 소재를 결정하지 않는다.
상위 후보 게임마다 유튜브 검색 결과를 확인한다.

검색어 예시:
- [게임명] 리뷰
- [게임명] 논란
- [게임명] 근황
- [게임명] 망한 이유
- [게임명] 과금
- [게임명] 쌀먹
- [게임명] 작업장
- [게임명] 자동사냥
- [게임명] 업데이트

수집 항목:
- 최근 1일~7일 영상 제목
- 조회수
- 업로드 시점
- 반복 키워드
- 큰 채널이 장악한 포맷
- 작은 채널도 조회수를 받은 틈새 각도
```

```markdown
### 유튜브 게임 홈 / 인기 급상승 확인

`https://www.youtube.com/gaming`에서 다음을 확인한다.

- 인기 실시간 스트림
- 인기 실시간 게임
- 인기 급상승 동영상
- 반복 노출되는 게임

일반 인기 급상승 페이지가 제한적으로 보일 경우, 유튜브 게임 홈과 검색 결과를 우선 사용한다.
```

추천 점수표:

| 지표 | 가중치 |
|---|---:|
| 유튜브 클릭 수요 | 30% |
| 방송 수요 | 20% |
| 커뮤니티/뉴스 이슈 | 20% |
| 채널 적합도 | 20% |
| 경쟁 강도 역가중 | 10% |

### 2.3 `korean-game-research` 개선 가능

현재 역할:

- 신작 게임 정보 조사
- 출시 일정 확인
- 대형 업데이트/사전예약 정보 정리
- 인벤/루리웹 등 커뮤니티 기반 조사

개선할 점:

- 신작 게임 정보에서 끝나지 말고 영상화 가능성까지 평가해야 한다.
- 커뮤니티 반응을 기대/불안/분노/실망/조롱/칭찬으로 분류해야 한다.
- 특정 채널과의 적합도를 별도로 봐야 한다.

추가할 규칙:

```markdown
### 영상화 가능성 평가

각 게임/업데이트마다 다음 항목을 평가한다.

- 지금 유튜브에서 검색될 이유가 있는가?
- 커뮤니티에서 반복되는 감정은 무엇인가?
- 영상 제목으로 뽑을 수 있는 갈등이 있는가?
- 직접 플레이나 공개 자료로 검증 가능한가?
- 특정 채널의 캐릭터와 맞는가?

출력에는 다음을 포함한다.

| 게임 | 출시/업데이트 | 커뮤니티 감정 | 영상화 포인트 | 추천 제목 | 우선순위 |
```

## 3. 새로 만들 만한 스킬

새 스킬은 여러 개보다 하나를 제대로 만드는 것이 좋다.

추천 신규 스킬:

> `korean-youtube-game-trend-scout`

한국어 이름:

> 한국 게임 유튜브 트렌드 스카우터

---

## 4. 신규 스킬 초안

### 이름

`korean-youtube-game-trend-scout`

### 목적

한국 게임 유튜브에서 지금 사람들이 클릭하는 게임과 이슈를 조사하고, 특정 채널에 맞는 영상 후보로 걸러주는 스킬.

단순 게임 인기 순위가 아니라, 유튜브 영상화 가능성과 채널 적합도까지 평가한다.

### 트리거 문장

다음 요청에서 사용한다.

- “요즘 게임 유튜브에서 뭐가 떠?”
- “지금 다뤄야 할 게임 찾아줘”
- “유튜브 인기 급상승 게임 영상 조사해줘”
- “게임 영상 소재 찾아줘”
- “어떤 게임으로 영상 찍으면 조회수 나올까?”
- “김실버 채널에 맞는 현재 이슈 게임 뽑아줘”
- “인기 게임/트렌드 기반으로 영상 기획해줘”

### 핵심 원칙

영상 기획은 다음 순서로 한다.

1. 지금 유튜브에서 노출되는 게임을 먼저 찾는다.
2. 최근 조회수가 붙는 검색 결과를 확인한다.
3. 방송 플랫폼에서 실제로 사람들이 보는 게임을 확인한다.
4. 커뮤니티/뉴스/패치/논란의 현재성을 확인한다.
5. 그중 채널의 캐릭터와 맞는 게임만 남긴다.
6. 남들이 이미 하는 제목을 피하고, 채널 고유 질문으로 재포장한다.

절대 바로 “이 영상 찍으세요”로 뛰지 않는다.  
먼저 지금 시청자가 무엇을 궁금해하는지 확인한다.

## 5. 신규 스킬 조사 루트

### 5.1 유튜브 게임 홈 / 인기 급상승 신호

우선 `https://www.youtube.com/gaming`을 확인한다.

확인할 것:

- 인기 실시간 스트림에 어떤 게임이 반복 노출되는가
- 인기 실시간 게임에 어떤 게임이 있는가
- 인기 급상승 동영상에 게임 영상이 있는가
- 한국어 제목 영상과 글로벌 영상을 구분한다
- 채널 주제와 맞지 않는 대형 상시 게임은 별도로 표시한다

주의:

- 일반 `https://www.youtube.com/feed/trending`은 로그인/지역/렌더링에 따라 데이터가 제한될 수 있다.
- 일반 인기 급상승이 비어 보이면, 유튜브 게임 홈과 검색 결과를 함께 사용한다.

### 5.2 유튜브 최근 검색 결과

후보 게임마다 유튜브 검색을 한다.

추천 검색어:

- `[게임명] 리뷰`
- `[게임명] 논란`
- `[게임명] 근황`
- `[게임명] 망한 이유`
- `[게임명] 과금`
- `[게임명] 쌀먹`
- `[게임명] 작업장`
- `[게임명] 자동사냥`
- `[게임명] 업데이트`
- `[게임명] 쇼케이스`

확인할 것:

- 최근 1일~7일 영상 중 조회수가 붙은 영상
- 제목에서 반복되는 키워드
- 큰 채널이 이미 장악한 포맷
- 작은 채널도 조회수를 받은 틈새 각도
- Shorts에서 터지는 감정 키워드

조회수만 보지 말고 업로드 시점과 함께 본다.  
예를 들어 5일 만에 20만 조회와 2년 동안 20만 조회는 완전히 다른 신호다.

### 5.3 방송 플랫폼 랭킹

가능하면 위플뷰/softc 같은 방송 카테고리 랭킹을 확인한다.

우선순위:

- 치지직 1일
- 치지직 1주일
- SOOP 1일
- SOOP 1주일
- 통합 1일
- 통합 1주일

확인할 것:

- 최고 시청자
- 평균 시청자
- 총 방송시간
- 구독자/팔로워 증가
- 1일 반짝인지 1주일 지속인지

필터링:

- 월드컵, 축구, 야구, 스포츠 이벤트는 게임 기획에서 제외하거나 별도 표시한다.
- talk, 종합 카테고리, 음악/노래, 여행 등 비게임 카테고리는 제외한다.
- 롤, 배그, 마크, 발로란트처럼 상시 대형 게임은 “시장 크기”와 “채널 적합도”를 분리해서 본다.

### 5.4 커뮤니티/뉴스 이슈 확인

후보 게임이 김실버식 이슈형 영상에 맞는지 확인한다.

확인할 키워드:

- 과금 논란
- 프모/BJ/광고 논란
- 작업장/매크로/자동사냥
- 거래소/쌀먹/재화 구조
- 패치 후 여론 변화
- 개발자 노트/공지 반응
- 추억 IP 복귀 반응
- 유저 이탈/동접/매출/평점 변화

커뮤니티 반응은 그대로 믿지 않는다.  
반드시 “반복되는 불만 패턴”과 “영상에서 검증 가능한 근거”를 구분한다.

## 6. 채널 적합도 평가 기준

각 게임을 다음 기준으로 평가한다.

| 항목 | 질문 |
|---|---|
| 클릭 수요 | 지금 사람들이 이 게임을 궁금해하는가? |
| 현재성 | 최근 1주일 안에 이슈/업데이트/논란이 있는가? |
| 경쟁 강도 | 이미 큰 채널이 같은 제목으로 장악했는가? |
| 차별화 가능성 | 이 채널만의 관점으로 바꿀 수 있는가? |
| 직접 플레이 가능성 | 실제로 해보고 근거를 만들 수 있는가? |
| 감정선 | 기대, 배신감, 분노, 아쉬움 같은 감정이 있는가? |
| 구조 해부성 | 과금, 운영, 자동, 프모, 거래, 작업장 구조를 설명할 수 있는가? |
| 구독 전환성 | 단발 조회수에서 끝나지 않고 채널 정체성을 강화하는가? |

김실버 채널 기준으로는 다음 소재에 가산점을 준다.

- 신작 MMORPG
- 리니지라이크
- 추억 IP의 모바일/클래식 부활
- 자동사냥/작업장/매크로
- 과금/프모/쌀먹/거래 구조
- 일반 유저가 밀려나는 구조
- “좋아했던 게임에게 배신당한 느낌”

다음 소재는 감점한다.

## 8. 김실버 채널 전용 판단 공식

김실버 채널에는 다음 공식을 적용한다.

> 인기 게임 / 이슈 게임  
> + 일반 유저의 불안과 배신감  
> + 직접 플레이 근거  
> + 과금·운영·자동·프모·거래 구조 해석  
> = 김실버식 게임 이슈 영상

김실버에게 맞는 제목은 단순히 “망했다”가 아니다.

좋은 제목:

- `이 게임이 욕먹는 진짜 이유, 일반 유저가 남을 자리가 없습니다`
- `이건 게임이 아니라 판처럼 느껴졌습니다`
- `추억은 살렸는데 왜 불안할까?`
- `신작 MMORPG 첫날에 반드시 봐야 할 5가지`
- `왜 유저가 운영사 대신 작업장을 잡고 있나`

피해야 할 제목:

- `2026 신작 MMORPG TOP10`
- `직접 해봤습니다`만 있는 제목
- `망겜입니다`만 있는 제목
- 전문 공략 채널처럼 보이는 제목
- 남의 인기 제목을 거의 그대로 따라 한 제목
