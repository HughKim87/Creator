- 성격: 운영 문제 진단 참고 문서. 기본 로드 금지.

## 0. 현재 결론

이 프로젝트는 현재 영상 제작 산출물을 가진 상태가 아니다.

사용자가 `workspace/`와 `temp/` 내용을 삭제했기 때문에, 백룸 원본, 자막, 기획서, 컷리스트, XML, 러프컷, 프레임 캐시, 과거 아카이브는 현재 기준으로 모두 없다.

남아 있는 것은 아래 세 종류다.

1. 규칙과 워크플로우 문서
2. 작업 스킬
3. 영상 분석/편집 보조 도구

따라서 다음 작업은 편집 재개가 아니라 **남아 있는 기준 체계를 정리하고, 각 단계별 작업방식을 개선·최적화하는 것**이다.

## 3. 남은 구조의 문제

1. 1, 2, 7단계 스킬은 있으나 기준이 얕다.
2. 3, 4, 8단계는 독립 스킬이 없다.
3. 5단계 규격은 남아 있지만, 배경 리서치 원문은 없다.
4. 과거 산출물이 사라졌기 때문에 백룸 영상은 처음부터 다시 해야 한다.
5. 문서들은 앞으로 삭제된 `workspace/`나 `temp/archive/`를 현재 기준처럼 가리키면 안 된다.

## 4. 정리 원칙

- 현재 기준은 남아 있는 파일만으로 판단한다.
- 없는 파일은 “아카이브에 있을 것”으로 가정하지 않는다.
- 새 영상 작업은 원본이 다시 제공된 뒤 시작한다.
- 편집은 각 단계별 작업방식 개선·최적화 후 진행한다.
- 새 문서는 `문서_인덱스.md`의 생성 게이트를 통과할 때만 만든다.
