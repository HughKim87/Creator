# Agent Core

- 목적: 프로젝트의 도메인 중립 Agent 기본 골조와 그 계약·검증·실패 지식을 소유한다.
- 읽는 시점: 기반 동작을 사용하거나, 명시적으로 승인된 core 변경을 검토할 때.
- 책임: 사용자가 변경 여부를 승인하고 프로젝트 에이전트가 승인된 최소 변경과 검증을 수행한다.
- 상태: 불변 보호 영역.
- 관련 권위: 루트 `PROJECT_RULES.md`, `AGENTS.md`, `core/rules/core-change-control.md`.

## 경계

`core/`에는 도메인 중립 기반만 둔다.

- 조건부 작업 절차
- 정보·기록·상태·지식·컨텍스트·검증 계약
- `file_data` 구현
- 공통 schema와 회귀 테스트
- 해결되고 재사용 가능한 기반 실패 지식

YouTube, 영상, 제작 workflow, 스킬, 개별 작업, runtime 데이터, 예시와 보고서는 `extension/`이 소유한다.

## 변경 보호

읽기와 승인된 인터페이스 실행은 허용된다. 파일 생성·수정·삭제·이동·이름 변경·재생성은 모두 core 변경이며 사전에 사용자의 명시적 승인이 필요하다.

자동 작업이 core 변경을 요구하면 작업을 실패로 종료하고 `extension/work/CORE_CHANGE_FAILURES.md`에 기록한다.
