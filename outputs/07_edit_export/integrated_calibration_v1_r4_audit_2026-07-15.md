# integrated-calibration-v1 r4 감사

- 기준 버전: `integrated-calibration-v1 r3`
- 현재 버전: `integrated-calibration-v1 r4`
- 상태: `CANDIDATE_READY_WITH_PLAYBACK_GAP`
- 역할: `calibration_candidate`
- 성공 목표: 구조·화면 사전점검 90점 이상
- 처리 범위: 7C 대표 캘리브레이션의 훅·B 행동 리듬·C 메시지와 엔딩
- 전체 편집·`approved_baseline`·`current_deliverable`: 승격 금지
- MP4 생성: 없음

## 결론과 점수

r3의 레드팀 점수 81점에서 드러난 반복 화면, 과설명, 중복 메시지, 문맥이 잘린 발화를 제거했다. r4의 **구조·화면 사전점검 점수는 92/100**이다. 이 점수는 원본 프레임, SRT, 무음 경계, 선택 구간 A/V 디코딩, XML 프레임 구조를 포함하지만 실제 연속 A/V 청취와 Premiere 앱 재생은 포함하지 않는다. 따라서 전체 영상 품질 점수나 최종 승인 점수가 아니다.

| 이야기·메시지 | 18/20 | 19/20 | C의 같은 뜻 반복과 문맥 불완전 문장을 제거해 중심 메시지를 직접화 |
| 캐릭터·코미디 | 17/20 | 19/20 | 훅의 반응→허세→붕괴, B의 발견→생쇼 코미디를 압축 |

## r3 → r4 편집 변경

### A 훅

- `A_HOOK_REVEAL 2333.865–2336.223`: 완결 cue “뭐? 뭐?”와 문 앞으로 접근하는 엔티티를 추가했다.
- `A_HOOK_TAUNT 2336.323–2338.837`: 반복 도발 전체 5.62초 대신 “못 들어오잖아” 뒤 `-35dB` 무음 경계까지 2.51초만 유지했다.
- `A_HOOK_BOAST`, `A_HOOK_FEAR`는 유지했다.
- `A_HOOK_ESCAPE`를 `2351.207`까지 연장해 마지막 대사 뒤 약 0.27초의 행동 결과와 공간음을 남겼다.
- r3의 `A_V2_HOOK_BOAST_ENTITY`를 제거했다. 화면은 문앞 접근→시선 이탈→창가 재등장 순서로 한 번만 진행한다.
- 훅 연결 길이: 12.39초→11.90초(60fps 프레임 기준). 10~16초 게이트를 통과한다.

### B 전원 사건

- `B_POWER_DISCOVERY`를 `3502.090–3507.953`에서 `3506.540–3507.940`으로 압축했다.
- 시청자의 위치 설명은 제거하고 김실버의 완결 반응 “전원 켜는 곳이 있었어요?”부터 시작한다.
- 실제 스위치 조작 2.4초와 밝은 결과 3.2초는 유지했다.
- B 연결 길이: 18.18초→13.72초.

### C 메시지와 엔딩

- `C_ADAPT`를 제거했다. `C_REPEAT`와 같은 뜻을 반복하고 첫 약 1.2초가 검은 화면이기 때문이다.
- `C_V2_REPEAT_FLASHBACK 4272.000–4274.000`을 `C_REPEAT` 첫 2초에 배치했다. 이미 지나온 통로에서 현재 통로로 넘어가 반복 학습을 시각화한다.
- `C_TENSE_BODY`를 제거했다. cue 경계는 맞지만 “해주고 싶어요”가 앞 문장에 의존해 단독 의미가 불완전하기 때문이다.
- 엔딩 검은 화면 덮개를 `C_V2_SIGNOFF_ROOM`과 `C_V2_CONFESSION_ROOM` 두 앵글로 분리했다.
- 자백 뒤 24프레임(0.4초) 여운은 유지했다.
- C 연결 길이: 약 26.43초→19.92초, 화면 tail 포함 20.32초.

## 검증 결과

- 품질 감사: `READY`, 20개 연결 컷, 미해결 0, 예외 0
- 멀티시퀀스 컷: 23개 = 연결 A/V 20개 + 무음 V2 3개
- 대표 샘플 연결 오디오 길이: 62.90초
- XML: 3개 시퀀스, A/B/C 비디오 트랙 수 `1/1/2`, 모든 비디오·오디오 소스/타임라인 프레임 길이 일치
- r2+r3+r4 생성기·XML·검토 페이지 회귀검사: 41개 통과
- 원본 선택 구간 A/V 디코딩: 23/23 성공
- 변경 범위 정렬: 훅 `-0.20초(0.596)`, B `0.00초(0.537)`, C 메시지 `-0.05초(0.945)`, C 엔딩 `0.00초(0.607)`
- 검토 페이지: static 플레이어, 원본 오디오 활성, 블라인드 모드, V2 전환, 마지막 무음 tail 로직 통과
- 신규 훅 프레임: 원본 `2332.0–2336.0` 9개를 자산 목록에 등록

## 레드팀

- 훅의 `2338.837`은 SRT cue 내부지만 `2338.644–2338.837` 무음 뒤에 자른다. 실제 의미 단위 청취 전까지 최종 경계라고 확정하지 않는다.
- 훅 뒤 E08→E01 시간 리셋은 콜드오픈 문법상 의도적이지만 여전히 에너지 변화가 크다. 현재 원본 오디오에서 안전한 추가 잔향은 약 0.27초뿐이다.
- B는 짧아졌지만 실제 스위치 조작 2.4초의 체감 길이는 연속 재생 전 확정할 수 없다.
- C의 과거 통로 V2는 이미 지나온 화면이라 미래 선공개는 아니지만, 회고 의도가 실제 재생에서 명확한지 확인이 필요하다.
- Premiere CS6 가져오기·오디오 L/R 재생과 실제 연속 음성 청취는 미검증이다.

## 반복 종료 판단

구조·화면 사전점검 성공 기준 90점을 넘겼고 자동 게이트의 미해결 항목도 없다. 남은 감점은 컷리스트를 더 잘게 나눈다고 해결되지 않고 실제 재생에서만 판단할 수 있다. 따라서 같은 근거로 r5를 생성하지 않는다. 다음 단계는 r4의 실제 A/V·Premiere 검증이며, 통과 전에는 전체 편집으로 확장하지 않는다.

## 한 가지 권고

r4의 `위협은 한 번만 진행 → 설명보다 발견 반응 → 같은 뜻 반복 제거 → 부인에서 최종 자백으로 직행` 문법을 현재 대표 기준으로 사용하되, Premiere에서 훅 도발 경계와 B 스위치 체감만 우선 확인한다.
