## 전체 배열

`HOOK_C09 → B01 → B02 → … → B18`

18비트는 컷 18개가 아니다. 각 비트 안에서 새 정보·행동·리액션 단위로 여러 microcut을 만들며,
비트 전체가 빠짐없이 이어져 “허세→붕괴→무서운 채 적응→아이러니 퇴장”을 구성한다.
