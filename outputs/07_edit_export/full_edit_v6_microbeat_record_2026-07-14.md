# 전체 편집 v6 microbeat 기록

## 공통 규칙

- 자막 선택은 복원 명령이 아니라 후보 신호로 취급한다.
- 각 후보에서 이야기 기능에 필요한 핵심 문장과 화면 행동만 남긴다.
- 반복 감탄, 조작 설명, 대기, 길 찾기 반복은 제거한다.
- 긴 컷은 화면 사건의 전조·행동·결과가 이어질 때만 허용한다.
- 훅은 문맥·최고점·종료 신호를 모두 포함하고 본문과 같은 원본을 반복하지 않는다.
