## 결론

초반·중간·후반 대표 샘플의 이야기 구조, 시간 순서, 화면 근거, 자막·무음 경계, XML 프레임 길이와 검토 페이지 계약은 통과했다. 원본의 선택 구간 20개는 영상과 AAC 스테레오 음성을 함께 오류 없이 디코딩했다. 다만 로컬 검토 페이지를 브라우저에서 여는 작업이 보안 정책으로 차단됐고, 현재 도구는 사람처럼 소리를 의미 단위로 청취했다고 증명할 수 없다. 따라서 실제 연속 A/V 재생·청취와 메타데이터를 가린 블라인드 재생은 미검증으로 남기며 최종 품질 승인이나 전체 품질 점수를 선언하지 않는다.

## 화면·음성 경계 증거

- 대표 원본 프레임: `outputs/06_analysis/source_assets/backrooms_20260630/frames/`
- A: 엔티티 위협, 창 너머 엔티티, 로비→백룸, VHS형 첫 공간을 확인했다.
- B: 암흑→전원 UI→밝은 방의 상태 변화를 확인했다.
- C: 어두운 통로→종료 벽돌방, 4914초 이후 검은 원본 화면, 동일 종료 공간의 V2 대체 화면을 확인했다.
- 동기·진입·엔딩의 긴 자막 큐는 원본 AAC 디코딩과 무음 경계 스캔으로 문장 단위 경계를 좁혔다.
- 오디오 정렬 결과: A -0.05초(0.650), B 0.00초(0.525), C1 0.00초(0.695), C2 0.00초(0.597).
- 선택 구간 20개 전체 원본 디코딩: 성공. 원본 오디오 `AAC / 48 kHz / stereo`.
- `webrtcvad` 부재로 VAD 전용 검사는 실행하지 못했고, 설치하지 않은 채 정렬과 ffmpeg 무음 스캔으로 대체했다.

## 의미 검토와 레드팀

- 중심 메시지는 검토 페이지에 정확히 한 번만 표시된다.
- 컷 순서와 선택 자막만으로 읽은 블라인드 가설: “호기심과 허세로 들어간 사람이 규칙을 배우고 웃어 넘기려 하지만, 익숙해져도 마지막까지 긴장은 남는다.”
- 이 문장은 실제 A/V 블라인드 재생 결과가 아니므로 `STORY-004` 통과 증거로 사용하지 않는다.
- A 위험: 강한 후반 훅과 초반 리셋이 분리되어 보일 수 있다. 대응은 리셋 직후 영화→게임→첫 공간만 남기고 미래 화면을 금지한 것이다.
- B 위험: 전원 발견 전 시간 점프가 크게 느껴질 수 있다. 대응은 어둠의 문제와 전원 행동, 밝아진 결과, 코미디만 한 사건으로 묶은 것이다.
- C 위험: 검은 원본 화면이 메시지 회수를 끊는다. 대응은 동일 종료 공간의 무음 V2만 사용해 음성 인과를 만들지 않고 시각 연속성만 보완한 것이다.
