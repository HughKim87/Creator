## 검증 페이지에서 먼저 볼 것

1. 원본 재생 카드가 화면 상단에 고정되지 않고 일반 스크롤로 사라지는지 확인한다.
2. B01~B06에서 백룸·리미널 관심과 반복 공간·소리의 논지가 실제로 느껴지는지 확인한다.
3. B07~B10에서 추격이 단순 비명 모음이 아니라 영화 관람과 직접 체험의 차이를 증명하는지 확인한다.
4. B12의 백룸·리미널 회고가 주차장 화면에서도 내용상 필수로 느껴지는지 확인한다.
5. B13~B17에서 빛·관찰 시설·구현 평가·소리 재해석이 하나의 분석 흐름으로 이어지는지 확인한다.
6. 모든 전환에서 말의 첫 음절이나 마지막 어절이 잘리지 않는지 실제 소리로 확인한다.

## Premiere에서 확인

1. `파일 > 가져오기`에서 `backrooms_full_18beat_v8.xml`을 선택한다.
2. `00_원본`, `01_후보클립`, `02_시퀀스` 빈이 생성되는지 확인한다.
3. 연결 창이 뜨면 `inputs/2026-06-30 00-23-03.mp4`를 지정한다.
4. `02_시퀀스 > FULL_전체18비트_v8`을 연다.
5. 영상 58클립, 오디오 L/R 각 58클립인지 확인한다.
6. B03, B07, B10의 긴 사건과 B12, B14, B17의 근거 제한을 우선 재생한다.

## 주의

- 새 MP4는 만들지 않았다. 사용자 지시 없이 렌더링하지 않는다.
- 자막 경계 검사는 통과했지만 자동 음성 파형 검사는 구성요소 부재로 미실행이다. 웃음·비명·숨소리는 실제 청취로 확인한다.
- B14는 관찰 시설 ‘추정’이며, B17은 특정 문 개방을 화면만으로 확정하지 않는다.
- v7 파일은 비교용 역사본이다. 사용자 승인 전 삭제하거나 덮어쓰지 않는다.
