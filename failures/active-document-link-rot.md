# 활성 문서의 끊어진 로컬 링크

- 상태: 해결·회귀 검증 완료
- 최초 확인: 2026-07-23 Stage 01.5 전체 문서 지도 검증
- 마지막 검증: 2026-07-23
- 적용 범위: 활성 Markdown 보고서, 문서 지도, 상대 링크

## 증상

활성 보고서의 관련 문서 링크가 실제로 존재하지 않는 과거 파일명을 가리켜 Markdown과 Obsidian에서 이동할 수 없었다.

## 확인된 원인

연결 대상 보고서의 최종 파일명에 추가된 `codex_` 식별자가 링크에는 반영되지 않았다. 개별 문서를 작성할 때 링크가 보였지만 전체 활성 문서의 실제 대상 존재 여부를 한 번에 검사하지 않아 남았다.

## 실패·해결 이력

| 시점·문맥 | 시도·결과 | 최고 연속 횟수 | 해결·검증 |
|---|---|---:|---|
| Stage 01.5 구조 게이트 3차 | `2026-07-22_프로젝트_의도_역추론_보고서.md` 대상이 없어 전체 링크 검사 중단 | 3 | 실제 정본인 `2026-07-22_codex_프로젝트_의도_역추론_보고서.md`로 링크를 보정하고 전체 게이트 재실행 |

최고 연속 횟수 3은 같은 전체 문서 구조 검증 목표에서 앞선 검사기 호환성 실패 두 건에 이어 발견된 횟수다. 세 시도의 원인은 구분해 기록하고, 링크 결함의 정본은 이 문서가 소유한다.

## 해결과 검증

- 링크 표시명에 Codex 출처를 명시하고 실제 보고서 파일명을 대상으로 보정했다.
- 활성 Markdown 전부의 로컬 링크 대상을 프로젝트 루트 기준으로 다시 검사했다.
- 보호 경로로 향하는 링크가 없고 전체 문서 지도에서 모든 활성 Markdown에 직접 이동할 수 있음을 함께 확인했다.

## 재사용 규칙

- 파일명 변경·문서 추가·단계 종료 뒤에는 활성 Markdown 전체의 상대 링크 대상 존재 여부를 검사한다.
- 링크 텍스트가 자연스러운지만 보지 말고 해석된 실제 경로가 루트 안의 파일인지 확인한다.
- 시점 보고서도 활성 지도에 남아 있는 동안 링크 무결성 검사 대상에 포함한다.
