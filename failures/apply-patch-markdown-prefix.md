# `apply_patch`와 Markdown 목록 기호 충돌

- 상태: 해결·회귀 검증 완료
- 최초 확인: 2026-07-23 다단계 문서 일괄 보정
- 마지막 검증: 2026-07-23
- 적용 범위: 패치 형식으로 Markdown 목록을 추가하는 문서 작업

## 증상

여러 단계 문서에 목록 문장을 일괄 추가하는 패치가 형식 오류로 두 번 거부됐다. 두 시도 모두 파일에는 적용되지 않았다.

## 확인된 원인

패치의 추가 행 표시 `+`와 Markdown 목록의 `-`를 분리해 작성하지 않아, 추가하려는 목록 행이 유효한 패치 행으로 해석되지 않았다.

## 실패·해결 이력

| 시점·문맥 | 시도·결과 | 최고 연속 횟수 | 해결·검증 |
|---|---|---:|---|
| 다단계 문서 일괄 보정 | 형식 오류 2회, 모두 무적용 | 2 | 추가 행을 `+- 목록 내용` 형태로 교정해 적용 성공, 대상 문서 재검사 후 활성 횟수 0 |

## 해결과 검증

- 패치 제어 기호와 문서 본문의 목록 기호를 별도 문자로 검토했다.
- 실패 시도가 무적용임을 확인한 뒤 수정 패치를 적용했다.
- 모든 단계 문서에 목표 문장이 존재하는지 다시 검색하고 diff를 검사했다.

## 재사용 규칙

- Markdown 목록 추가 행은 패치의 `+` 다음에 본문의 `-`가 오는지 확인한다.
- 일괄 패치 전에 한 문서의 작은 패치로 형식과 문맥을 확인한다.
- 패치 실패 뒤 재시도하기 전에 부분 적용 여부를 먼저 확인한다.
