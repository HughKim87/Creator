# 06. 영상제작에서 AI 역할 분리

- 작성일: 2026-07-08
- 상태: Generated
- 적용 필요성: 필수

## 1. 문제 정의

사용자의 목표는 AI에게 맡길 수 있는 일을 줄이는 것이 아니다. 오히려 생산성을 높이기 위해 AI에게 맡길 수 있는 일은 최대한 맡겨야 한다.

문제는 AI에게 맡길 일과 사용자가 최종 판단해야 할 일을 구분하지 않은 것이다.

AI는 반복 처리, 후보 추출, 비교, 표 정리, 도구 실행에 강하다. 하지만 채널 감각, 재미, 편집감, 최종 메시지 판단은 불안정하다.

## 2. AI에게 적극 맡길 작업

| 영역 | 맡길 수 있는 작업 |
|---|---|
| 리서치 | 게임 이슈 수집, 방송/검색 수요 비교, 커뮤니티 반응 정리 |
| 자막 분석 | 반복 표현, 감정 변화, 전환점 후보 추출 |
| 기획 보조 | 후보 메시지 여러 개 만들기, 지지/반박 대사 정리 |
| 영상 분석 | 특정 구간 프레임 추출, 화면/자막/오디오 근거 표 정리 |
| 후보 비교 | 대표/예비/제외 후보 분류 초안 |
| 편집 준비 | 컷리스트 CSV, XML, EDL, 러프컷 초안 생성 |
| 검증 | 형식 검증, 누락 확인, 경계 스캔, 도구 실행 결과 확인 |
| 문서화 | 산출물 메타데이터와 인계 브리프 정리 |

## 3. AI가 혼자 확정하면 안 되는 작업

| 영역 | 이유 |
|---|---|
| 최종 소재 선택 | 채널 방향, 현재 관심사, 사용자 감각이 필요하다. |
| 영상 핵심 메시지 확정 | 대사 근거뿐 아니라 채널 톤과 영상 의도가 필요하다. |
| "재미있는 장면" 최종 선택 | AI는 리액션 크기와 실제 시청 재미를 혼동할 수 있다. |
| 최종 컷 흐름 승인 | 편집 리듬과 체감 길이는 사용자 판단이 필요하다. |
| 제목/썸네일 최종 결정 | 클릭 감각과 채널 맥락이 필요하다. |
| 업로드 여부 판단 | 최종 책임과 품질 기준은 사용자에게 있다. |

## 4. 역할 분리 모델

```text
사용자 = 편집장 / 최종 판단자
AI = 조사원 + 조수 편집자 + 데이터 정리자 + 도구 실행자
```

AI가 해야 하는 질문:

1. 현재 기준은 무엇인가?
2. 후보를 어떻게 좁힐 것인가?
3. 근거는 어디에 있는가?
4. 어떤 부분을 사용자가 판단해야 하는가?
5. 다음 단계로 넘겨도 되는가?

AI가 하면 안 되는 행동:

1. 사용자의 승인 없이 다음 단계로 넘어가기.
2. 근거 없이 메시지 확정하기.
3. 긴 영상 전체를 이해했다고 가정하기.
4. 결과물이 마음에 들지 않는데 같은 방식으로 재생성하기.

## 5. 외부 자료와의 연결

AnimAgents 연구는 창작 작업에서 AI가 단순 생성자가 아니라 단계 조율자와 보조자로 작동해야 하며, 사용자 통제와 중간 산출물 관리가 중요하다고 분석한다.

출처: https://arxiv.org/abs/2511.17906

OpenAI Agents SDK 문서도 복잡한 작업에서 human review가 필요한 지점을 두라고 설명한다.

출처: https://developers.openai.com/api/docs/guides/agents

## 6. 프로젝트에 필요한 적용안

1. 각 단계마다 `AI 작업`과 `사용자 판단`을 분리해서 적는다.
2. 사용자가 판단해야 하는 지점에서는 AI가 산출물을 만들지 않고 후보/근거만 제시한다.
3. AI가 확정해도 되는 것은 형식, 누락, 기술 검증 같은 기계적 판단으로 제한한다.
4. 스킬 문서에 "AI가 확정하지 말 것" 섹션을 추가한다.
5. 최종 결정이 필요한 산출물에는 `사용자 승인 필요` 상태를 표시한다.

## 7. 단계별 역할 분리 초안

| 단계 | AI 역할 | 사용자 역할 |
|---:|---|---|
| 1 | 소재 후보와 근거 수집 | 최종 소재 선택 |
| 2 | 콘셉트 후보와 제목 방향 제안 | 채널 관점 확정 |
| 3 | 대본 구조 초안 작성 | 톤과 주장 승인 |
| 4 | 자막 정리와 오류 후보 표시 | 원문 의미 변경 여부 확인 |
| 5 | 대사 근거와 후보 메시지 비교 | 컨트롤링 아이디어 확정 |
| 6 | 화면/자막/오디오 근거 지도 작성 | 대표 후보 선택 |
| 7 | 편집 자료 생성 | 컷 흐름 승인 |
| 8 | 체크리스트 검수 | 최종 업로드 판단 |

## 8. 적용하지 말아야 할 방식

1. AI를 총괄 프로듀서처럼 쓰지 않는다.
2. AI에게 최종 취향 판단을 맡기지 않는다.
3. 사용자가 불만족한 기준을 AI가 추측해서 보정하게 하지 않는다.
4. "자동화"를 "최종 결과 품질 보장"으로 착각하지 않는다.
