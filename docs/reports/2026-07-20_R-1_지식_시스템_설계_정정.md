# R-1 지식 시스템 설계 정정 — 보존 표식

- 작성일: 2026-07-20
- 상태: R-1의 대체된 설계 제안 / 원문은 Git에 보존 / 기본 컨텍스트 제외
- 목적: R-1에서 11개 상시 커널과 18개 조건부 규칙을 제안했다가 R-1.1 보정이 필요해진 이력을 추적한다.
- 사용 시점: R-1과 R-1.1의 차이를 명시적으로 감사하거나 대체 경위를 확인할 때만 사용한다.
- 작성·수정 주체: 에이전트가 보존 식별자와 현재 경로를 유지하고, 설계 권위 변경은 사용자가 승인한다.
- 언어: 한국어.
- 저장 위치: `docs/reports/2026-07-20_R-1_지식_시스템_설계_정정.md`.
- 연결 관계: 현재 제안은 [R-1.1 설계 보정](2026-07-20_R-1.1_지식_시스템_설계_보정.md), 보정 필요성은 [착수 전 의도 검증](2026-07-20_R-2_착수전_사용자_의도_정합성_검증.md), 승인된 이전 기준은 [기반 및 지식 시스템 설계](2026-07-20_프로젝트_기반_및_지식_시스템_설계.md)가 소유한다. 보존·검색 상태는 [문서 지도](../agent/DOCUMENT_MAP.md)가 소유한다.
- 권위: 역사적 증거만 가진다. 현재 정책·설계·절차나 R-2A 구현 권한을 제공하지 않는다.
- 기본 컨텍스트: 제외. 사용자가 과거 R-1 원문 또는 11/18 제안을 정확히 지정한 경우에만 Git 원문을 연다.

| 마지막 전체 원문 커밋 | `f1d7c66d5fe70c2b6b3858d1f47c80cafa00f659` |
| Git blob | `683e594e5fac886f348f7703296dad113b227af2` |

| 원문 규모 | 648줄, UTF-8 |

원문은 위 Git 객체로 완전히 복원할 수 있다. 현재 작업 트리에는 같은 설계를 반복하지 않기 위해 보존 식별자와 대체 관계만 둔다.

## 역사적 요약

- R-1은 기존 29개 규칙을 상시 커널 11개와 조건부 규칙 18개로 나누는 안을 제시했다.
- 조건부 규칙의 정본 형식, 파일 내부 addressable unit, 실제 read/write vertical slice 시점과 최종 운영 검증 단계가 사용자 의도에 충분히 맞지 않았다.
- 이 제안은 승인되지 않았고, 현재 설계 검토 대상은 R-1.1 하나뿐이다.
