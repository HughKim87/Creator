# Stage 00 위험과 롤백

- 역할: 활성 위험, 보호 범위, 롤백 기준.
- 읽는 시점: Stage 00 보완 또는 Stage 01 승인 전.
- 보존 조건: 안정화 완료 전까지.

## 1. 활성 위험

1. legacy `run_python.bat`이 자식 비정상 종료를 성공으로 바꾸는 결함이 재현됐다.
2. 29개 테스트와 공통 검증 도구가 금지 데이터 경로에 결합돼 현재 정책 아래 실행 불가다.
3. 현재 pre-commit은 검사기 결손을 성공으로 처리한다.
4. 현재 CI는 루트에 없는 검사·테스트 경로를 참조한다.
5. 데이터 경계는 현재 문서와 생성기에는 반영됐지만 Stage 01의 자동 검사·테스트·훅은
   아직 구현되지 않았다.

## 2. 정정 완료 위험

초기 인벤토리가 사용자 데이터의 파일별 메타데이터를 저장한 문제는 다음과 같이
정정했다.

- 잘못된 schema v1 매니페스트·스냅샷을 schema v2로 제자리 덮어씀
- 실제 사용자 데이터 식별자와 파일별 메타데이터 검색 결과 0건
- 인벤토리 입력을 Git 추적 프레임워크 파일로 제한
- 재귀 파일시스템 열거 제거
- `PROJECT_RULES.md`를 단일 데이터 경계 정본으로 지정

## 3. 보호 범위

- `backup/`은 읽기 전용이다.
- `inputs`·`outputs` 경로 세그먼트는 파일 접근 전에 차단한다.
- 사용자 데이터의 경로·이름·수·크기·해시를 프레임워크 보고서에 기록하지 않는다.
- Stage 00 보고서와 재현 가능한 작은 증거는 Git 추적하고, 임시 실행 환경은 제외한다.
- legacy 실행이 필요하면 별도 승인된 worktree에서 코드·테스트만 사용한다.

## 4. 롤백 기준

| 항목 | 값 |
|---|---|
| 구체계 마지막 정상 배치 후보 | `8a6ce44068a348c65f21ca69f6cf857aa51fc79b` |
| 구체계 이동 커밋 | `eba0d74` |
| 제안 태그 | `legacy-pre-rebuild-2026-07-16` |
| 신규 애플리케이션·DB | 없음 |
| legacy 실행 worktree | 검증 완료 후 제거; 재생성은 별도 승인 필요 |

태그는 생성하지 않았다. 이번 정정은 추적 문서의 Git 복구와 사용자 승인된 Stage 00
보고서 제자리 수정으로 관리하며 중복 백업 파일을 만들지 않는다.

## 5. 즉시 중단 조건

- 검사기가 Git 추적 목록 밖의 파일시스템을 재귀 열거함
- 금지 경로 또는 민감 패턴을 파일 접근 전에 차단하지 못함
- `backup/` Git diff가 발생함
- 범위 밖 사용자 변경과 충돌함
- 외부 전송, 비용, 권한 변경이 필요함
