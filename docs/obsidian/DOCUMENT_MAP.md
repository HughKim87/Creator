## 경계

- 이 지도는 전체 경로 목록이나 현재 값을 복제하지 않는다.
- `reports/`와 완료 stage owner는 참고·역사이며 현재 지시가 아니다.
- `backup/`, `inputs/`, `outputs/`, `.git/`, `.obsidian/` 내부는 미색인이다.
