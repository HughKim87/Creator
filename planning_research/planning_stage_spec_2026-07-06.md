# 기획 단계 규격 — 승인 데이터에서 통합 메시지 도출 (v3 · 2026-07-15)

- 역할: 촬영 완료본의 데이터 분석 뒤, 편집 전에 수행하는 영상 기획 운영 규격
- 읽을 때: 승인된 원본 근거지도에서 시청자 약속·중심 메시지·스파인을 만들 때
- 유지 기준: `docs/WORKFLOW_CONTRACT.json`의 단계 순서와 함께 사용
- 과거 기획·컷리스트·편집본은 비교 자료이며 현재 근거 기준본이 아니다.

## 한 줄 정의

이 단계는 이야기를 지어내는 일이 아니라, **승인된 원본 근거에서 대상 시청자가 볼 이유와 한 개의 중심 메시지를 선택하고 모든 이야기 비트를 그 메시지에 연결하는 일**이다.

## 목표

영상 기획은 아래 질문에 답해야 한다.

- 이 영상을 보러 온 시청자에게 무엇을 보여주겠다고 약속하는가?
- 영상 전체를 관통하는 말은 정확히 한 개인가?
- 그 말은 어떤 원본 대사·화면·사건 근거로 뒷받침되는가?
- 주인공은 처음과 끝 사이에 무엇이 달라지는가?
- 반례·약점·확인되지 않은 근거를 숨기지 않았는가?
- 대표 편집에서 무엇을 실제 영상과 음성으로 먼저 확인해야 하는가?

좋은 로그라인보다 전체 원본을 덜 왜곡하고, 대상 시청자의 관심과 인물 체험을 함께 설명하는 기획이 우선이다.

## 입력

필수 입력:

- 승인된 데이터 분석 `CURRENT.json`과 근거지도
- 고정된 `source_id`, 원본 지문, 원본 시간 기준
- 원본 자막 또는 전사와 타임코드 신뢰도
- 데이터 근거 ID별 사건·화면·대사·시청자 관심·반증·재검증 판정
- 사용자가 정한 대상 시청자 가설과 제외 조건

선택 입력:

- 과거 기획서: 실패 원인과 회수할 요소 비교에만 사용
- 과거 편집본: 현재 기획의 근거로 사용 금지

데이터 분석이 승인되지 않았거나 핵심 근거가 원본 시간으로 추적되지 않으면 시작하지 않는다.

## 절차

### 1. 기준 입력 고정

기획서 첫 부분에 아래를 기록한다.

- 원본 영상과 원본 자막
- `source_id`와 지문
- 승인 데이터 분석 버전·경로
- 사용한 근거 ID
- 자막·오디오·화면 검증 한계
- 비교한 과거 기획과 승계하지 않은 판단

### 2. 시청자 약속 정의

시청자 약속은 한 문장으로 쓴다.

포함해야 할 것:

- 어떤 관심으로 들어온 시청자인가
- 이 영상에서 어떤 체험·질문·변화를 보게 되는가
- 그 약속을 지지하는 데이터 근거 ID

금지:

- 외부 수요 자료 없이 시장 전체가 좋아한다고 단정
- 관련 없는 화면 위에 설명만 얹어 소재 의미를 주입
- 영상에 없는 정보·세계관·인과를 약속

### 3. 후보 메시지 비교

중심 메시지를 바로 고정하지 않고 2~3개 후보를 비교한다.

| 항목 | 필수 내용 |
|---|---|
| 후보 메시지 | 한 문장 |
| 지지 근거 | 원본 대사·화면·사건 ID 5개 이상 |
| 반례·약점 | 2개 이상 |
| 대상 시청자 적합성 | 시청자 약속과의 연결 |
| 인물 변화 설명력 | 시작·변화·끝을 설명하는지 |
| 판정 | 채택·탈락 이유 |

탈락 우선순위:

1. 재검증 근거를 사실로 단정해야 성립한다.
2. 반례를 숨겨야 성립한다.
3. 논지가 두 개 이상으로 갈라진다.
4. 캐릭터 반응 또는 장르 관심 한쪽만 남긴다.
5. 화면보다 설명이 앞선다.

### 4. AI 권고 중심 메시지 한 개

권고 문장은 아래를 만족해야 한다.

- 한 문장이다.
- 시작과 끝의 변화를 포함한다.
- 모든 조각이 원본 대사 또는 화면 근거로 추적된다.
- 같은 기능의 장면을 걸러낼 수 있다.
- 반례와 함께 읽어도 성립한다.
- AI 자체 검토 전에는 `draft`, G1~G5 통과 뒤에는 `approved_for_calibration`이다. 사용자 판단은 대표 샘플 이후로 미룬다.

### 5. 근거 연결 스파인

스파인은 원본 사건 순서를 기본으로 하며, 콜드오픈 후보를 제외한 미래 화면 삽입을 전제로 하지 않는다.

| # | 근거 ID·원본 범위 | 핵심 대사·화면 | 이야기 기능 | 중심 메시지 기여 | 인물 변화 | 제외 시 손실 | 편집 전 검증 |
|---:|---|---|---|---|---|---|---|

모든 비트는 새 정보를 하나 이상 가져야 한다. 비슷한 비명·탐색·규칙 설명은 대표와 예비로 구분한다.

### 6. 캐릭터 변화와 긴장-이완

캐릭터 변화는 감정 라벨만 나열하지 않는다.

| 구간 | 시작 상태 | 사건·행동 | 바뀐 인식·태도 | 근거 ID | 공포 직후 이완·코미디 |
|---|---|---|---|---|---|

`허세 → 붕괴 → 학습 → 적응`처럼 단순화할 때는 끝의 반례가 없는지 확인한다. 공포가 남는다면 극복으로 표현하지 않는다.

### 7. 포함·축소·제외·재검증

포함:

- 중심 메시지의 조각을 직접 증명한다.
- 감정이나 인식이 바뀐다.
- 대상 시청자의 장르 관심을 화면·행동으로 충족한다.
- 같은 기능의 다른 장면보다 새 정보가 있다.

축소:

- 중요한 대사지만 화면 정보가 약하다.
- 같은 규칙·공포 반응을 반복한다.
- 맥락에 필요한 방송 운영·설정 설명이다.

제외:

- 중심 메시지에 기여하지 않는 메뉴·방송 관리·사운드 조정
- 같은 기능만 반복하는 탐색·비명·실패
- 관련 없는 화면 위 긴 소재 설명
- 데이터 단계에서 폐기된 합성 후보나 비연속 몽타주

재검증:

- 실제 청취 없이 소리의 원인·인과를 단정해야 하는 구간
- 표본 프레임만으로 사건 대상·결과가 선명하지 않은 구간
- 자막 끝시간이나 발화 경계가 신뢰되지 않는 구간

### 8. 편집 캘리브레이션 브리프

기획서 마지막에는 대표 편집이 먼저 확인할 항목을 적는다.

- 훅 후보의 사건·감정 피크·결과가 실제 AV에서 이어지는가
- 훅 뒤 장르 핵심 공간 진입이 설명보다 늦지 않은가
- 발화가 문장 중간에서 잘리지 않는가
- 화면 전환이 필요하면 음성을 유지한 J/L컷이 가능한가
- 추격·규칙 발견이 발견-행동-결과 단위로 성립하는가
- 공포 직후 코미디와 이완이 남는가
- 화면과 대사의 의미가 충돌하지 않는가
- 미래 화면을 현재 이야기 시점에 잘못 삽입하지 않는가

이 항목은 컷 경계나 XML이 아니다. 실제 AV 검증 질문이다.

### 9. 자체 레드팀 검토

사용자에게 제시하기 전에 AI가 아래 반론을 직접 검사한다.

1. 대상 시청자의 관심을 실제 장면이 아니라 설명으로만 충족시키는가?
2. 중심 메시지가 두 개 이상의 분석 체크리스트로 갈라지는가?
3. 캐릭터 재미를 장르 분석이 덮어버리는가?
4. 반례를 숨기거나 진행자의 추정을 게임 사실로 바꾸는가?
5. 재검증 장면이 훅·결론·세계 규칙의 필수 근거인가?
6. 같은 기능의 비트 하나를 빼도 아무 손실이 없는가?
7. 사용자가 첫 결함 탐지자가 되게 만드는 미검증 항목이 남았는가?

실패한 항목은 기획서 안에서 수정하고, 남는 한계만 명시한다.

## 출력 순서

1. 산출물 상태
2. 기준 입력과 검증 한계
3. 시청자 약속
4. 후보 메시지 비교
5. AI 권고 중심 메시지 한 개
6. 근거 연결 스파인
7. 캐릭터 변화와 긴장-이완
8. 포함·축소·제외·재검증
9. 반례·약점
10. 편집 캘리브레이션 브리프
11. 자체 레드팀 검토
12. 게이트 판정

## 완료 게이트

### G1. 시청자 약속

- 승인된 시청자 관심 근거와 연결된다.
- 영상이 실제로 제공할 수 있는 체험을 약속한다.

### G2. 중심 메시지 한 개

- 중심 메시지가 정확히 한 문장이다.
- 모든 스파인 비트가 같은 메시지에 기여한다.
- 반례와 함께 읽어도 성립한다.

### G3. 캐릭터 변화

- 시작·변화·끝이 원본 순서와 근거 ID로 추적된다.
- 장르 분석 때문에 캐릭터 반응과 이완이 사라지지 않는다.

### G4. 근거 연결 스파인

- 모든 비트가 데이터 근거 ID와 원본 시간에 연결된다.
- 각 비트의 새 정보와 제외 시 손실이 명확하다.
- 화면이 약한 설명과 실제 화면 근거를 구분한다.

### G5. AI 자체 검토

- 레드팀 반론을 AI가 먼저 검사하고 수정했다.
- 재검증 항목이 사실로 승격되지 않았다.

### G6. 대표 캘리브레이션 전달

- G1~G5가 통과하면 상태를 `approved_for_calibration`으로 바꾼다.
- 이 상태는 초반·중간·후반의 제한된 대표 샘플 제작만 허용하며 전체 편집 기준본은 아니다.
- 사용자의 창작 방향 판단은 텍스트 기획서가 아니라 AI가 실제 AV를 자체 검증한 대표 샘플 이후에 한 번 받는다.
- 대표 샘플 승인 전에는 전체 편집 잠금 해제와 `approved_baseline` 승격을 금지한다.

## 이 단계에서 하지 않는 것

- 실제 컷 취사와 컷 경계 확정
- XML·EDL·러프컷 생성
- 실제 AV 재생 없이 훅·추격·소리 인과 확정
- 최종 영상 품질 점수 선언
- 사용자 승인 대신 AI가 전체 편집 방향을 최종 확정
