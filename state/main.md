# Creator main 공통 개발 상태

- 목적: 공통 제작 기능의 최신 재개 지점과 검증 경계를 안내한다.
- 읽는 시점: 시작 문서 뒤. 책임: 공통 유지보수 Agent와 사용자.
- 상태: active / 승인된 로컬 보완 완료. same-workspace.
- 관련 권위: PROJECT_RULES.md, extension/docs/WORKSPACE.md.

## 현재 단계

목적별 영상 제작 안내는 extension/docs/domain/youtube/VIDEO_PURPOSE_WORKFLOWS.md다. 총괄은 필요한 목적과 실제 입력(원본 컷/자료와 별도 음성 합성)에 맞춰 기존 스킬을 연결한다. 규칙·프로필을 복제하거나 모든 영상에 전체 분석·TTS·XML·새 승인을 강제하지 않는다.

extension/src/video_scene_cache.py는 job renderer가 사용하는 입력·overlay·렌더 코드·설정에 결속된 구간 cache다. 기존 합성기를 대체하지 않으며 호출자가 승인된 입력, 실제 renderer 의존성, 검증 함수와 job 잠금을 제공한다. 자료 변경·cache 손상·입력 누락·렌더 중 변경을 검사한다.

대본 목적·근거·낭독·국소 수정은 write-video-script, 기존 플레이 컷은 edit-gameplay-video가 소유한다. NotebookLM의 VIDEO_JOB 엔진과 Premiere 전달 계약은 그대로다. 영상별 현재판은 각 job/state.md만 소유한다. Sprite 개발기 job은 r09와 잠긴 대본·가이드 음성을 보존했다.

## 직전 게이트

장면 cache 회귀 7개, 제작 스킬 묶음 회귀 6개와 무결성 검사가 pass다. 기존 TTS 변경은 로컬 TTS 환경에서 엔진 11개·VoxCPM2 10개 테스트를 통과했다. 이 증거는 도구·연결·합성 fixture 수준이며 실제 다음 영상의 품질·작업시간 개선이나 전체 시청을 입증하지 않는다.

## 승인 상태

사용자는 main에서 기존 변경을 보존한 보완과 로컬 커밋을 승인했고, 이후 기존 local change도 내용별로 커밋하도록 승인했다. TTS·런처 변경, 캐릭터 자산, 채널 분석 결과를 별도 작업으로 보존했다. 채널 PDF에서 재생성 가능한 페이지 PNG 19개만 정확한 삭제 승인을 받아 제거했다. Core 변경·설치·원격 push·외부 게시·기존 영상 수정은 제외했다.

## 차단

공통 보완의 미해결 차단은 없다. 현재 영상의 전체 시청·직접 청취·사용자 승인은 해당 job에서 대기한다.

## 알려진 위험

실제 TTS GPU 생성·대화형 UI와 아바타 앱 import·마이크 동작은 이번에 재실행하지 않았다. 채널 통계는 관측 당시 자료이며 최신 수치를 다시 조회하지 않았다. 실행 로그는 디스크에 보존하되 Git에서 제외한다. ignored jobs/runtime은 Git 커밋으로 복구되지 않는다.

이전 E2 실제 전편 평가와 E3 오디오 피크 관련 보류, 공식 Chrome 런타임 의존·무결성 목록 확장 검토는 별도 요청 전 유지한다. 이전 근거는 extension/docs/reports/SESSION_CLOSE_GAMEPLAY_2026-10-23.md와 관련 커밋을 참조한다. 기존 개인·legacy 스킬은 자동 교체하지 않는다.

## 첫 다음 행동

1. 새 영상은 목적과 실제 입력에 맞는 경로를 선택하고 해당 job의 상태·접근 승인·필요한 기존 스킬만 확인한다.
2. 다중 자료 합성 renderer를 공용 cache에 연결할 때 입력과 실행 코드의 누락 없는 결속 및 실제 출력 검증을 확인한다. 현재 r09 생성기를 이미 이 경로로 교체했다고 주장하지 않는다.
3. 실제 결과를 확인할 때 자동 검사·정지 표본·연속 시청·직접 청취·사용자 승인을 구분한다. 실제 성과 검증이 필요한 후속 요청에서만 별도 평가한다.
